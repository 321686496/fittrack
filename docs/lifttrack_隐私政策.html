LiftTrack 隐私政策

版本 v4.0 生效日期 2026-09-03

1一、我们收集的信息

  1. 设备标识符（device_id）：首次启动时在设备本地自动生成、用于区分设备的 UUID，不包含任何可识别你个人身份的信息
  2. 训练数据（训练计划、动作、组数、重量、次数、休息时间、进行中的训练进度）
  3. 身体数据（身高、体重、体脂、围度等由你主动填写的数据及其历史记录）
  4. 训练笔记（你主动记录的文字与图片内容）
  5. 健身卡信息（卡片类型、剩余次数、到期日期，仅用于提供到期与次数提醒）
  6. 应用设置（主题、深色模式、单位、默认组数次数、提醒时间、积分、成就、虚拟物品解锁状态、邀请记录等）
  7. 你主动提供的图片素材（自定义动作封面、自定义头像，仅保存在设备本地）
我们遵循「最小必要」原则：仅收集为你提供健身服务所必需的信息，不收集姓名、手机号、通讯录、精确位置等与核心功能无关的信息。本应用无需注册账号，相关数据均在你主动操作下产生并保存在你的设备上。

2二、信息使用方式

  1. 提供训练计划制定、实时训练记录、数据统计、身体数据追踪、教学课程、虚拟对手、成就积分与虚拟物品兑换等核心功能
  2. 在你主动操作时，通过本地通知发送训练提醒、休息倒计时提醒、健身卡到期提醒与智能推送提醒（通知内容均由本机生成，不经过任何服务器）
  3. 在你主动操作时生成训练海报、邀请二维码、分享卡片，并调用系统分享功能
  4. 对邀请码、激活识别码、分享码进行本地校验（HMAC-SHA256），以激活邀请奖励或导入分享计划
  5. 在你主动操作时导出全部数据（复制到剪贴板或 JSON），用于备份或迁移到其他设备
  6. 本应用不接入任何第三方广告 SDK，不展示第三方广告，不采集用于广告的标识符（IDFA/OAID 等），不存在任何形式的广告追踪

3三、信息存储位置

  1. 训练数据、身体数据、应用设置与笔记等均存储在你的设备本地（SQLite 数据库 + SharedPreferences + 应用文件目录），不会上传至任何服务器
  2. 本应用完全离线运行，不联网、不传输你的任何训练数据与个人数据
  3. 本地数据受系统沙盒与各平台安全机制保护，其他应用无法直接访问
  4. 因数据仅保存在设备本地，不存在数据出境情形

4四、第三方 SDK 信息共享

  1. share_plus（系统分享）：仅在你主动点击分享时才调用系统分享面板传递相关内容
  2. mobile_scanner / zxing2（二维码扫描与识别）：全部在设备本机完成，不上传任何图像
  3. image_picker / image_gallery_saver（本地选图与保存海报）：全部在设备本机完成
  4. flutter_local_notifications / permission_handler（本地通知与系统权限）：仅用于在设备本地调度提醒与申请系统权限
  5. url_launcher（跳转链接）：仅用于跳转至应用商店评分页等功能入口
  6. audioplayers（音频播放）：仅用于在设备本地播放休息倒计时提示音，不采集任何音频
  7. 我们不会将你的信息出售、出租或共享给任何第三方用于营销，也不含任何广告 SDK

5五、未成年人保护

  1. 本应用面向成年健身爱好者，不面向未满 14 周岁的未成年人提供服务
  2. 我们不主动收集未成年人信息
  3. 若监护人发现未成年人误用本应用，可联系下方邮箱申请删除相关数据；本地数据亦可由你本人在应用内「数据与隐私」页面随时清除

6六、用户权利

  1. 查询：通过「数据与隐私」页面可查看全部本地数据，并可复制导出（粘贴为 JSON）
  2. 更正：可在应用内直接修改身体数据、训练记录、设置与笔记
  3. 删除：通过「清除数据」功能一键清空本地数据（需确认，清除后不可恢复）
  4. 授权管理：通知、相机、相册等系统权限可随时在系统设置中开启或关闭；关闭后仅影响对应功能，核心训练记录功能不受影响
  5. 无需账号注销：本应用无需注册账号，数据全部保存在设备本地，清除全部数据即视为完成删除
