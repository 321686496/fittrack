01 / 设计逻辑

从 FitTrack 名字本身拆解设计

不再依赖任何中文品牌名或附加概念，纯粹从「FitTrack」英文名本身拆解 —— Fit（健身/适配）+ Track（追踪/轨迹/记录），用字母图形化 + 力量元素做减法设计。

名称拆解 · Fit + Track

Fit（健身/力量）+ Track（追踪/记录/轨迹）= FitTrack

FitTrack 这个名字本身就已经完整表达了产品定位 —— "健身追踪"。LOGO 应该让名字自己说话：要么把 F 图形化为力量元素（杠铃/哑铃），要么把 Track（追踪）视觉化为轨迹/圆环/对勾。不需要再附加额外的概念。

F = Fit（力量） T = Track（追踪） Track = 轨迹/圆环/对勾 Fit = 杠铃/哑铃

03 / LOGO 方案

四套极简字母图形化方案

全部围绕 FitTrack 英文名的字母 F / T 做图形化，融合力量元素（杠铃/哑铃）或追踪元素（圆环/对勾/轨迹），每个方案只用一个核心图形，做减法不做加法。

设计说明

字母 F（FitTrack 首字母）的竖线 = 杠铃杆，横线 = 杠铃片。F 本身就是一根杠铃的抽象形态 —— 上横较长（大重量片），中横较短（小重量片），呼应杠铃配重层次。

  • LOGO 即品牌字母，认知成本最低，看一眼就知道是 FitTrack
  • 图形极简（一个 F 字母），24×24 极小尺寸仍清晰可辨
  • 横线长短不一呼应杠铃配重，富有层次又不失简洁
  • 几何块面构成，现代感强，应用商店图标识别度高
  • 可适配 Favicon、Tab 图标、启动页等多种窄长场景

追踪圆环（带缺口的圆，Track=追踪轨迹）+ 内嵌 F 字母（FitTrack 首字母）。圆环顶部的缺口处有一个小圆点，象征"追踪进行中"。

  • Track = 追踪，圆环是最直观的"追踪/循环"视觉符号
  • 圆环 + F 双重图形，同时承载 Fit + Track 两个词的含义
  • 圆环缺口处的追踪点增加动感和品牌识别度
  • 几何感强，符合现代极简设计趋势（类似 Apple Fitness+）
  • 圆环可做加载进度动画，动效潜力强

左半部分是 F 字母（FitTrack 首字母），从 F 的中横起笔延伸出一道对勾（✓）。F = 品牌，对勾 = 记录完成 / 打卡，组合含义："FitTrack 帮你完成并记录每一次训练"。

  • F + 对勾双重图形，同时承载品牌字母与"记录完成"功能感
  • 对勾自带正向反馈，每次看到 LOGO 都有"完成"的愉悦感
  • 对勾可延伸为训练完成动画、打卡反馈等品牌资产
  • 小尺寸（Tab 栏/Favicon）可简化为纯对勾，依然可辨
  • F 字母与对勾自然衔接，不是生硬拼贴

字母 T（Track 首字母）本身就是一根哑铃的形态 —— 横线 = 哑铃杆+两侧配重，竖线 = 哑铃握把。T = 哑铃，是最自然、最巧妙的字母图形化。

  • T 字母天然就是哑铃形态，无需额外装饰，"做减法"的极致
  • 横线两端的配重块面强化"哑铃"识别度，又不失字母 T 的可读性

  • 24×24 极小尺寸下依然清晰可辨

设计师推荐

方案 1（F·杠铃） 与 方案 4（哑铃·T） 可作为系列设计 —— F = 杠铃，T = 哑铃，两个字母都是力量器械的自然形态，品牌系统感最强。

  • 主 LOGO 用 方案 1（F·杠铃）：F 是首字母，更适合作为主标识
  • 方案 4（T·哑铃）可作为辅助图形：用于 Tab 栏、加载动画、水印等场景
  • 两个方案都极简，24×24 仍清晰，多平台适配无忧
