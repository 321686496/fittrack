## 一、产品概述

### 1.1 产品定位

**FitTrack 燃力** 是一款面向国内健身爱好者的**纯本地 + 轻服务器**健身训练追踪应用。核心训练数据完全存储在设备本地，不上传、不联网；服务器仅用于可选增值功能（排行榜、兑换码验证），用户可随时关闭联网权限而不影响核心体验。

### 1.2 目标用户

| 画像   | 描述                            |
| ---- | ----------------------------- |
| 核心人群 | 25-40 岁，有一年以上训练经验的健身爱好者       |
| 地域分布 | 一线及新一线城市为主                    |
| 使用场景 | 健身房力量训练，需要记录组数/重量/次数/休息时间     |
| 痛点   | 现有 APP（Keep/训记）功能臃肿、隐私担忧、操作复杂 |
| 核心诉求 | 简洁的开箱即用、本地数据存储、深度数据追踪         |

### 1.3 核心价值主张

> **"你的私人训练笔记本 —— 纯本地，不追踪，不骚扰，只做好一件事：帮你记录每一次训练。"**

### 1.4 v2 版本目标

| 维度 | v1 基线     | v2 目标                |
| -- | --------- | -------------------- |
| 变现 | 单一 Pro 买断 | 广告 + Pro + 兑换码三层变现   |
| 流量 | 无体系化获取    | 内容营销 + KOC 合作 + 分享裂变 |
| 留存 | 无主动留存机制   | 日历热力图 + 智能推送 + 成就系统  |
| 合规 | 无明确合规方案   | 全功能适配国内四大应用商店        |

| **管理项**  | 匿名参与排行榜开关（默认关闭）、推送通知开关、数据导出、数据清除（本地全部数据）、账号注销（清除服务器匿名账号） |
| **验收标准** | 用户点击"数据清除"后无确认弹窗误操作可能，需二次确认；清除后 APP 恢复至首次启动状态            |
