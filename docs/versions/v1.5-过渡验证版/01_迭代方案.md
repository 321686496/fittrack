# FitTrack 燃力 v1.5 过渡验证版 迭代方案

> 版本：v1.5 | 更新日期：2026-07-14 | 文档状态：正式
> 前置条件：v1 获客留存版达标（累计≥3000、7日留存≥25%、DAU/MAU≥30%）

---

## 一、版本定位

### 1.1 一句话定位

> **v1.5 = 在已验证留存的基础上，引入高级功能验证付费需求，通过 adgate（看广告按次使用）赚取过渡收入，为 v2 付费转化铺路。**

### 1.2 核心策略

| 策略 | 说明 |
|------|------|
| 功能分层 | 核心留存功能免费 + 增量内容 adgate + 高级功能基础版免费 |
| adgate 边界 | 只对增量内容 adgate，核心训练智能层基础版免费开放 |
| 收入过渡 | 广告收入从"防零"升级为"过渡盈利" |
| 需求验证 | 通过高级功能使用率验证 v2 Pro 功能的付费潜力 |
| 不破坏 v1 | 获客引擎继续运转，广告不打扰核心训练流程 |

### 1.3 功能分层原则（最关键的设计决策）

```
┌─────────────────────────────────────────────────────┐
│  核心训练智能层（v1.5 免费基础版 → v2 Pro增强版）       │
│  智能重量推荐 / 疲劳度评估 / 高级计划编排               │
│  → v1.5 免费开放基础版，验证需求                       │
│  → v2 推出增强版（Pro专属），基础版仍可 adgate          │
│  → 绝不做 adgate → 避免锚定在"广告价格"上               │
├─────────────────────────────────────────────────────┤
│  增量内容层（v1.5 adgate → v2 Pro去广告）              │
│  额外专题教学 / 美化月报 / 额外主题 / 计划库预览        │
│  → v1.5 看广告按次使用                                │
│  → v2 Pro用户免广告，adgate路径保留                    │
│  → 锦上添花，不伤核心体验                               │
├─────────────────────────────────────────────────────┤
│  留存核心功能（v1.5 保持免费 → v2 保持免费）           │
│  虚拟对手 / 高级统计 / 训练资产卡 / 彩蛋 / 7天留存链     │
│  → 全版本免费，不做 adgate                             │
└─────────────────────────────────────────────────────┘
```

### 1.4 与 v1 / v2 的关系

| 维度 | v1 获客留存版 | v1.5 过渡验证版 | v2 盈利加速版 |
|------|-------------|---------------|-------------|
| 核心目标 | 获客+留存 | 需求验证+过渡收入 | 盈利加速 |
| 付费体系 | 无 | 无 | Pro订阅 |
| 广告策略 | 2位激励视频（克制） | 2位激励 + adgate增量内容 | adgate保留 + Pro免广告 |
| 高级功能 | 不开发 | 基础版免费+增量内容adgate | 增强版Pro + 基础版adgate保留 |
| 裂变 | 教学功能解锁 | 保持 | 升级Pro时长裂变 |

## 二、v1.5 新增功能

### 2.1 核心训练智能层（基础版，免费开放）

#### 智能重量推荐（基础版）

基于用户历史训练数据，自动推荐下次训练的目标重量：

```
上次卧推：4组 × 8次 × 70kg
→ 推荐：4组 × 8次 × 72.5kg（渐进超负荷 +2.5kg）
→ 原理：上周成功完成目标次数 → 微增重量
```

基础版功能：
- 基于上一次同动作数据推荐增量（+2.5kg/+5kg）
- 推荐显示在训练执行页"上次70kg，建议尝试72.5kg"
- 用户可采纳或忽略

v2 增强版（Pro专属）：
- 基于多周趋势的智能推荐（不只看上一次，看4周趋势）
- 疲劳度修正（疲劳高时建议减重）
- 个性化增量算法（不固定2.5kg，按动作/水平动态调整）

#### 疲劳度评估（基础版）

基于训练量+频率简单计算疲劳度：

```
近7天训练量评分：██████░░ 75%（中高疲劳）
建议：今天练腿（上肢未恢复），或安排休息日
```

基础版功能：
- 按肌群计算近7天训练量
- 简单三档：低/中/高疲劳
- 首页卡片提示"上肢疲劳度较高，建议练腿"

v2 增强版（Pro专属）：
- 综合疲劳曲线（含恢复时间预测）
- 过度训练警告
- 周期化建议

#### 高级计划编排（基础版）

免费版支持线性计划，v1.5 开放基础超级组：

基础版功能：
- 支持超级组（两个动作背靠背）
- 支持递减组（同动作递减重量）
- 简单的波浪负荷（轻重-重轻交替）

v2 增强版（Pro专属）：
- 完整周期化编排（大循环/中循环/小循环）
- 自动化渐进超负荷编排
- 模板化超级组/巨人组设计

### 2.2 增量内容层（adgate，看广告按次使用）

以下功能 v1.5 通过看广告解锁单次使用，v2 Pro用户免广告：

| 增量内容 | adgate 触发 | 用户获得 | 频次 |
|---|---|---|---|
| 额外专题教学 | 点击专题→看广告 | 解锁1个专题教学包查看权限 | 不限 |
| 美化月报 | 月底→看广告 | 1次精美月度进步报告（含图表美化+趋势分析） | 每月1次 |
| 额外主题 | 主题页→看广告 | 解锁1套额外主题（永久） | 每套1次 |
| Pro计划库预览 | 计划页→看广告 | 预览1套专业计划详情（可导入使用7天） | 每周1次 |

设计要点：
- adgate 只在用户主动点击时触发，不打断任何流程
- 增量内容不影响核心训练体验，不 adgate 也能正常使用 APP
- 每次广告解锁的内容有明确时效（专题永久/月报当月/计划7天）

### 2.3 广告位扩展

v1.5 广告位从 v1 的2个扩展为：

| 广告位 | 来源 | 触发 | 说明 |
|---|---|---|---|
| 训练完成详细报告 | v1保留 | 用户主动点击 | 裂变3人激活后消失 |
| 高级报告单次体验 | v1保留 | 用户主动点击 | 每天1次 |
| 增量内容 adgate | v1.5新增 | 用户主动点击专题/月报/主题/计划 | v1.5核心广告收入来源 |

### 2.4 v1 功能保持不变

以下 v1 功能在 v1.5 完全保持：
- 虚拟对手（增加对手教学互动彩蛋）
- 高级统计（保持免费）
- 教学裂变（保持功能解锁激励）
- 训练彩蛋、资产卡、计划进度链
- 推送策略
- 分享码UGC

## 三、阶段目标与验证

### 3.1 v1.5 验证目标

| 验证项 | 达标标准 | 说明 |
|---|---|---|
| 智能推荐使用率 | ≥40%训练时采纳推荐 | 验证付费需求 |
| 疲劳度查看率 | ≥30%用户每周查看 | 验证付费需求 |
| 高级编排使用率 | ≥20%计划使用超级组 | 验证付费需求 |
| adgate内容使用率 | ≥25%用户看过至少1次 | 验证广告收入潜力 |
| 月广告收入 | ≥¥1,500 | 过渡收入验证 |
| 7日留存 | ≥25%（不低于v1） | 确认广告不影响留存 |
| DAU/MAU | ≥30%（不低于v1） | 确认广告不影响粘性 |

### 3.2 未达标怎么办

- 智能推荐使用率<40%：推荐算法不够准或触达不够，优化推荐逻辑
- adgate使用率<25%：增量内容不够吸引，优化内容质量
- 留存/DAU下降：广告打扰了用户，减少 adgate 频次或内容
- 月广告收入<¥1,500：用户基数不足，继续 v1 获客动作

### 3.3 v1.5→v2 启动条件

| 检查项 | 标准 |
|---|---|
| 智能推荐使用率 | ≥40% |
| 疲劳度查看率 | ≥30% |
| 累计用户 | ≥5,000 |
| 月广告收入 | ≥¥1,500 |
| 7日留存 | ≥25%（未下降） |

## 四、风险与应对

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| adgate 损坏口碑 | 中 | ASO受损 | adgate只在增量内容，核心功能免费；广告15秒可跳过 |
| 用户认为"广告变多" | 中 | 留存下降 | 严格限制 adgate 频次，监控留存数据 |
| 智能推荐不准 | 中 | 信任受损 | 基础版先做简单线性推荐，避免过度复杂 |
| 高级功能开发量大 | 低 | v1.5延期 | 基础版优先，增强版推迟到v2 |
