# FitTrack 燃力 v1.5 过渡验证版 迭代方案

> 版本：v1.2 | 更新日期：2026-07-16 | 文档状态：调优版
> 前置条件：v1 获客留存版达标（累计≥3000、7日留存≥25%、DAU/MAU≥30%）

---

## 一、版本定位

### 1.1 一句话定位

> **v1.5 = 在已验证留存的基础上，引入高级功能验证付费需求，通过 adgate（看广告按次使用）赚取过渡收入，为 v2 付费转化铺路。**

### 1.2 核心策略

| 策略 | 说明 |
|------|------|
| 功能分层 | 核心留存功能免费 + 增量内容解锁 + 高级功能基础版免费 |
| 增量内容解锁 | 只对增量内容设解锁门槛，核心训练智能层基础版免费开放 |
| 收入过渡 | 解锁收入从"防零"升级为"过渡盈利" |
| 需求验证 | 通过高级功能使用率验证 v2 Pro 功能的付费潜力 |
| 不破坏 v1 | 获客引擎继续运转，解锁不打扰核心训练流程 |
| 品牌一致性 | 将"广告"重新包装为"赞助解锁"，保持"无广告"品牌承诺（详见2.2节） |

> 调优说明：原方案使用"adgate"一词容易让用户联想到"广告"，与v1建立的"无广告"品牌定位冲突。建议统一使用"赞助解锁"或"免费解锁"话术，弱化商业感，强化"用户主动选择换取价值"的正面感知。

### 1.3 功能分层原则（最关键的设计决策）

```
┌─────────────────────────────────────────────────────┐
│  核心训练智能层（v1.5 免费基础版 → v2 Pro增强版）       │
│  智能重量推荐 / 疲劳度评估 / 高级计划编排               │
│  → v1.5 免费开放基础版，验证需求                       │
│  → v2 推出增强版（Pro专属），基础版仍可 adgate          │
│  → 绝不做 adgate → 避免锚定在"广告价格"上               │
├─────────────────────────────────────────────────────┤
│  增量内容层（v1.5 adgate → v2 Pro去广告）              │
│  额外专题教学 / 美化月报 / 额外主题 / 计划库预览        │
│  → v1.5 看广告按次使用                                │
│  → v2 Pro用户免广告，adgate路径保留                    │
│  → 锦上添花，不伤核心体验                               │
├─────────────────────────────────────────────────────┤
│  留存核心功能（v1.5 保持免费 → v2 保持免费）           │
│  虚拟对手 / 高级统计 / 训练资产卡 / 彩蛋 / 7天留存链     │
│  → 全版本免费，不做 adgate                             │
└─────────────────────────────────────────────────────┘
```

### 1.4 与 v1 / v2 的关系

| 维度 | v1 获客留存版 | v1.5 过渡验证版 | v2 盈利加速版 |
|------|-------------|---------------|-------------|
| 核心目标 | 获客+留存 | 需求验证+过渡收入 | 盈利加速 |
| 付费体系 | 无 | 无 | Pro订阅 |
| 解锁策略 | 2位激励视频（克制） | 2位激励 + 增量内容赞助解锁 | 解锁保留 + Pro免解锁 |
| 高级功能 | 不开发 | 基础版免费+增量内容解锁 | 增强版Pro + 基础版解锁保留 |
| 裂变 | 教学功能解锁 | 保持 | 升级Pro时长裂变 |

## 二、v1.5 新增功能

### 2.1 核心训练智能层（基础版，免费开放）

#### 智能重量推荐（基础版）

基于用户历史训练数据，自动推荐下次训练的目标重量：

```
上次卧推：4组 × 8次 × 70kg
→ 推荐：4组 × 8次 × 72.5kg（渐进超负荷 +2.5kg）
→ 原理：上周成功完成目标次数 → 微增重量
```

基础版功能：
- 基于上一次同动作数据推荐增量（+2.5kg/+5kg）
- 推荐显示在训练执行页"上次70kg，建议尝试72.5kg"
- 用户可采纳或忽略
- **增强判断**：若上次做了4组且最后1组用户标记"有余力"，则推荐+5kg；若最后1组标记"吃力"，则推荐+0kg（保持）
  > 调优说明：原方案仅"基于上一次"推荐太简单，增加"余力/吃力"判断后推荐更有"智能感"，让用户觉得"这个APP懂我"，为v2增强版铺路

v2 增强版（Pro专属）：
- 基于多周趋势的智能推荐（不只看上一次，看4周趋势）
- 疲劳度修正（疲劳高时建议减重）
- 个性化增量算法（不固定2.5kg，按动作/水平动态调整）

#### 疲劳度评估（基础版）

基于训练量+频率简单计算疲劳度：

```
近7天训练量评分：██████░░ 75%（中高疲劳）
建议：今天练腿（上肢未恢复），或安排休息日
```

基础版功能：
- 按肌群计算近7天训练量
- 简单三档：低/中/高疲劳
- 首页卡片提示"上肢疲劳度较高，建议练腿"

v2 增强版（Pro专属）：
- 综合疲劳曲线（含恢复时间预测）
- 过度训练警告
- 周期化建议

#### 高级计划编排（基础版）

免费版支持线性计划，v1.5 开放基础超级组：

基础版功能：
- 支持超级组（两个动作背靠背）
- 支持递减组（同动作递减重量）
- 简单的波浪负荷（轻重-重轻交替）

> 调优说明：超级组和递减组涉及训练执行核心流程改动，建议拆分为两个迭代——v1.5.1先上超级组（UI改动小、用户需求高），v1.5.2再上递减组（涉及重量自动递减逻辑，复杂度更高）。避免一次性开发量过大导致延期。

v2 增强版（Pro专属）：
- 完整周期化编排（大循环/中循环/小循环）
- 自动化渐进超负荷编排
- 模板化超级组/巨人组设计

### 2.2 增量内容层（赞助解锁，看视频按次使用）

> **品牌调优**：将"adgate"统一更名为"赞助解锁"或"免费解锁"。在APP内展示为"看一段小视频，免费解锁XXX"，而非"看广告"。保持v1建立的"无广告"品牌承诺——用户感知是"用少量时间换取价值"，而非"被广告打扰"。

以下功能 v1.5 通过赞助解锁单次使用，v2 Pro用户免解锁：

| 增量内容 | 解锁触发 | 用户获得 | 频次 |
|---|---|---|---|
| 额外专题教学 | 点击专题→赞助解锁 | 解锁1个专题教学包查看权限 | 不限 |
| 美化月报 | 月底→赞助解锁 | 1次精美月度进步报告（含图表美化+趋势分析） | 每月1次 |
| 额外主题 | 主题页→赞助解锁 | 解锁1套额外主题（永久） | 每套1次 |
| Pro计划库预览 | 计划页→赞助解锁 | 预览1套专业计划详情（可导入使用7天） | 每周1次 |

设计要点：
- 解锁只在用户主动点击时触发，不打断任何流程
- 增量内容不影响核心训练体验，不解锁也能正常使用 APP
- 每次解锁的内容有明确时效（专题永久/月报当月/计划7天）

> 调优补充：建议增加"功能试用"机制
> - 高级功能基础版每次训练可试用1次增强版（如智能推荐可试用"多周趋势推荐"1次）
> - 试用后弹出轻量提示："这是增强版推荐，升级Pro每次训练都能享受"
> - 目的：让用户体验到增强版的甜头，为v2付费转化铺路
> - **频次硬编码**：各解锁位的频次上限必须在代码层面硬编码，防止运营为追求收入临时加量

### 2.3 广告位扩展

v1.5 广告位从 v1 的2个扩展为：

| 广告位 | 来源 | 触发 | 说明 |
|---|---|---|---|
| 训练完成详细报告 | v1保留 | 用户主动点击 | 裂变3人激活后消失 |
| 高级报告单次体验 | v1保留 | 用户主动点击 | 每天1次 |
| 增量内容 adgate | v1.5新增 | 用户主动点击专题/月报/主题/计划 | v1.5核心广告收入来源 |

### 2.4 v1 功能保持不变

以下 v1 功能在 v1.5 完全保持：
- 虚拟对手（增加对手教学互动彩蛋）
- 高级统计（保持免费）
- 教学裂变（保持功能解锁激励）
- 训练彩蛋、资产卡、计划进度链
- 推送策略
- 分享码UGC
- 一键裂变流程（剪贴板+二维码+App Linking，保持不变）

### 2.5 v1.5 轻服务器层——正式引入服务端能力

v1阶段已用纯本地+UX设计补偿了裂变流程摩擦。v1.5阶段（需求已验证+过渡收入支撑成本），正式引入轻服务器层，进一步优化裂变体验和业务安全。

#### 服务器能力清单

| 能力 | 说明 | 数据上传 |
|---|---|---|
| **裂变验证服务端** | 邀请码生成→绑定→激活→奖励发放全链路（被邀请者激活后自动入账，无需二次确认） | 邀请关系（邀请人ID+被邀请人匿名ID+时间戳） |
| **内容分发** | 教学动作库JSON托管CDN，实时更新 | 不上传，仅下载最新内容 |
| **用户系统（轻）** | 仅绑定邀请关系+激励次数，跨设备累计 | 匿名ID = 设备ID哈希（不可逆），邀请关系+激励记录 |
| **防刷增强** | 服务端设备指纹预处理，为v2数据积累基础 | 匿名设备指纹特征 |

#### 不上传的数据（维护"训练数据纯本地"承诺）

| 不上传的数据 | 说明 |
|---|---|
| 训练记录 | 训练数据永不离开设备 |
| 身体数据 | 体重/身高等健康数据纯本地 |
| 训练笔记 | 笔记内容纯本地 |
| 个人信息 | 任何可识别个人身份的信息 |

#### 成本预估

| 服务 | 月成本 | 说明 |
|---|---|---|
| 云函数（2个） | ¥50-100 | 邀请验证+内容分发接口 |
| MySQL最小实例 | ¥100-200 | 邀请关系+激励记录存储 |
| CDN流量 | ¥30-80 | 教学JSON下载 |
| 合计 | ¥250-500/月 | **低于v1.5最低解锁收入¥800，打平** |

#### 隐私合规要求

| 要求 | 说明 |
|---|---|
| 隐私政策更新 | 明确说明上传"匿名邀请关系+激励记录"，不上传训练数据 |
| 隐私政策入口 | 首次启动弹窗 + 设置页常驻入口 |
| 数据删除权 | 提供"删除我的邀请关系数据"入口 |
| 匿名ID不可逆 | 设备ID哈希（SHA-256），无法反查真实设备 |

#### v1.5 一键裂变流程升级（对比v1）

| 维度 | v1纯本地 | v1.5+轻服务器 |
|---|---|---|
| 激活动作 | 扫码→安装→点击确认（1步） | 扫码→安装→**自动激活（0步）** |
| 激励到账 | 本地存储，重置丢失 | 服务端存储，跨设备继承 |
| 防刷 | 仅防自邀，接受多设备损耗 | 服务端校验，基本根治 |
| 教学内容 | 发版时更新 | 云端实时下发（新动作即时可见） |
| 邀请关系 | 本地保存，重置丢失 | 云端保存，永久保留 |
| 奖励累计 | 本地计数，重置清零 | 服务端保存，可累计使用 |

#### 与v1的衔接——平滑过渡

v1已有的邀请码+一键迁移策略：v1邀请数据→v2自动迁移，已解锁教学/主题永久保留。

## 三、阶段目标与验证

### 3.1 v1.5 验证目标

| 验证项 | 最低标准 | 理想标准 | 说明 |
|---|---|---|---|
| 智能推荐使用率 | ≥30% | ≥40%训练时采纳推荐 | 验证付费需求 |
| 疲劳度查看率 | ≥20% | ≥30%用户每周查看 | 验证付费需求 |
| 高级编排使用率 | ≥15% | ≥20%计划使用超级组 | 验证付费需求 |
| 解锁内容使用率 | ≥20% | ≥25%用户看过至少1次 | 验证解锁收入潜力 |
| 月解锁收入 | ≥¥800 | ≥¥1,500 | 过渡收入验证（原方案¥1,500偏乐观，需DAU≥2,500才能达到） |
| 7日留存 | ≥25%（不低于v1） | ≥25%（不低于v1） | 确认解锁不影响留存 |
| DAU/MAU | ≥30%（不低于v1） | ≥30%（不低于v1） | 确认解锁不影响粘性 |

> 调优说明：原方案月广告收入¥1,500目标需要DAU≥2,500才能达到（DAU/MAU≈83%几乎不可能）。建议调低最低标准至¥800（DAU 1,500时可达），理想标准保持¥1,500。

### 3.2 未达标怎么办

- 智能推荐使用率<40%：推荐算法不够准或触达不够，优化推荐逻辑
- adgate使用率<25%：增量内容不够吸引，优化内容质量
- 留存/DAU下降：广告打扰了用户，减少 adgate 频次或内容
- 月广告收入<¥1,500：用户基数不足，继续 v1 获客动作

### 3.3 v1.5→v2 启动条件

| 检查项 | 标准 |
|---|---|
| 智能推荐使用率 | ≥30%（最低）/ ≥40%（理想） |
| 疲劳度查看率 | ≥20%（最低）/ ≥30%（理想） |
| 累计用户 | ≥5,000 |
| 月解锁收入 | ≥¥800（最低）/ ≥¥1,500（理想） |
| 7日留存 | ≥25%（未下降） |

## 四、风险与应对

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 赞助解锁损坏口碑 | 中 | ASO品牌受损 | 统一使用"赞助解锁"话术，弱化广告感知；解锁内容15秒可跳过 |
| 用户认为"广告变多" | 中 | 留存下降 | 严格限制解锁频次（代码硬编码），监控留存数据 |
| 智能推荐不准 | 中 | 信任受损 | 基础版先做"余力/吃力"增强判断，避免过度复杂 |
| 高级功能开发量大 | 中 | v1.5延期 | 拆分为v1.5.1（超级组）和v1.5.2（递减组）两个迭代 |
| 月收入不达标 | 中 | v2启动推迟 | 设最低标准¥800，未达标时优先加获客而非加解锁位 |

| 高级编排基础版（免费） | 增强版Pro专属 |

> 调优补充：v1.5末期（达标后启动v2开发时）建议开始预告"下一代FitTrack正在开发更强大的智能训练分析"，让用户有心理预期，避免v2上线时用户感觉"突然收费"。

> **调优补充——v1.5→v2感知降级防护**：
> - v1.5用户已习惯"基础版免费"，v2推出"增强版Pro专属"后可能产生"基础版被阉割"的感知
> - 建议在v2上线推送中强调："基础版功能保持不变，Pro是升级选项"而非"以下功能需付费才能使用"
> - 具体话术示例："FitTrack 2.0新增智能推荐增强版、疲劳分析增强版等专业功能（Pro专属）。你目前使用的所有功能保持不变，基础版永久免费。"
> - 在APP内Pro购买页面顶部展示对比表，明确标注"基础版（永久免费）"和"Pro版（升级选项）"
