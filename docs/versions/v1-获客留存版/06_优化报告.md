## 二、变更明细

### 新增文件

#### 1. `lib/data/virtual_opponent.dart` — 虚拟对手系统（§E1）

- 4 层水平分布（休闲/规律/活跃/硬核），每周训练次数/时长/重量范围按层级配置
- `VirtualOpponentEngine` 单例：生成 300+ 对手池（40%/30%/20%/10% 分布）
- `advanceWeekly()`：周日独立推进，不依赖用户训练事件
- `computeOutcome()`：胜负分布真实化（碾压 25% / 胶着 50% / 被吊打 25%）
- `computePercentile()`：同水平层超越百分比采样
- `matchTierByWeeklyTarget()`：冷启动匹配
- **Dart 2.x 兼容**：使用 `Range` / `MatchOutcome` 类替代 Dart 3 records 语法

#### 2. `lib/data/tutorial_content.dart` — 教学信息体系（§D1）

- `TutorialDifficulty` / `MuscleGroup` / `TutorialType` 枚举
- `Tutorial` 数据类 + `TutorialLibrary` 静态库
- 内容：6 基础 + 3 进阶 + 1 专题 + 1 大师教程
- 方法：`getBasic()` / `getAdvanced(unlockedCount)` / `getTopic(bool)` / `getMaster(bool)` / `groupByMuscle()`

#### 3. `lib/services/invitation_service.dart` — 邀请裂变系统（§C1）

- 邀请码格式：`FIT-INV-XXXXXX`（Base32，去除 0/O/1/I 易混字符）
- 独立 HMAC 密钥：`fitTrack_invitation_secret_v1_2026`（与兑换码系统隔离）
- 防自身邀请：deviceId 哈希前缀比对
- 里程碑解锁：1/3/5/10 次激活 → 解锁进阶教程/大师教程/对手皮肤/大使称号
- 被邀请人激励：7 天高级统计全开放体验
- `isAdvancedStatsAvailable()`：v1 全免费策略下始终返回 `true`

#### 4. `lib/services/share_code_service.dart` — UGC 分享码系统（§C2）

- 分享码格式：`FITT-XXXXXX`（与邀请码 `FIT-INV-` 区分）
- 独立 HMAC 密钥：`fitTrack_sharecode_secret_v1_2026`
- `generateShareableString()`：`FITT-XXXXXX|<base64-json>` 完整分享串
- `importFromString()`：支持完整串或纯码校验
- `ImportWarning` 枚举：excessiveVolume(>50 组) / excessiveFrequency(>7 次/周)
- `attachAuthorSignature()`：作者签名附加

## 五、发现的问题与建议

### 已修复

1. **Dart 3 records 语法不兼容**：`virtual_opponent.dart` 初版使用 `(int, int)` / `(double, double)` 返回类型，在 Dart 2.x 项目中编译失败。已重构为 `Range` / `MatchOutcome` 类。
2. **`List<String>` 包含 null 元素**：`_statusTemplates` 混入 `null` 表示无动态，类型应为 `List<String?>`。已修复。
3. **`await` 作用于同步 `bool`**：`invitation_service.dart` 中 `await Storage.saveSettings()` 返回 `bool` 非 `Future`。已移除多余 `await`。
4. **未使用导入**：`share_code_service.dart` 中 `import '../data/storage.dart'` 未使用。已移除。

### 预存在（未处理，建议单独修复）

1. `storage.dart:137` — `await saveSettings(s)` 同样存在 `await_only_futures`，建议统一移除。
2. `profile_page.dart:9` — `ohos_reminder_service.dart` 未使用导入，建议移除。
3. `profile_page.dart` / `settings_page.dart` — 20 处 `prefer_const_constructors` 风格提示，建议批量优化。
4. `widget_test.dart` Timer 泄漏 — 预存在问题（见 project_memory）。
