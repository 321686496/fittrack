# FitTrack 燃力 v1 获客留存版 运营目标

> 版本：v1.0 | 更新日期：2026-07-14 | 文档状态：正式

---

## 一、运营总目标

> **v1 运营核心 = 获客引擎跑通 + 留存验证达标。不追求收入，追求"用户愿意来、愿意留"。**

| 指标 | v1 目标 | 说明 |
|---|---|---|
| 累计用户 | ≥3,000 | 启动v1.5的硬性阈值 |
| 7日留存 | ≥25% | 健身类优秀线 |
| 30日留存 | ≥15% | 留存验证 |
| DAU/MAU | ≥30% | 粘性验证 |
| 裂变K因子 | ≥1.1 | 裂变机制有效 |
| 周均新用户 | ≥200 | 获客引擎跑通 |
| 月广告收入 | ¥200-1,200 | 防零收入，非盈利目标 |

## 二、获客策略

### 2.1 HarmonyOS原生红利（第一优先）

这是个人开发者能拿到的最便宜的流量，必须第一时间申请。

| 动作 | 说明 | 时间 |
|---|---|---|
| 华为应用市场原生应用认证 | 申请"鸿蒙原生精选"标识 | 上线前 |
| 申报鸿蒙扶持位 | HarmonyOS NEXT升级期有流量倾斜 | 上线即报 |
| 关键词优化 | 覆盖"鸿蒙健身""原生健身记录"等 | 持续 |

### 2.2 ASO长尾词策略

避开Keep垄断的大词，选差异化长尾词：

| 关键词类型 | 示例 | 策略 |
|---|---|---|
| 隐私差异化 | "无广告健身记录""本地训练日记""隐私健身APP" | 核心差异化 |
| 功能长尾 | "力量训练记录PR""杠铃训练记录""渐进超负荷" | 精准用户 |
| 场景长尾 | "健身房训练笔记""居家训练记录" | 场景匹配 |
| 避免 | "健身""运动""Keep" | 被大厂垄断，不竞争 |

### 2.3 小红书内容营销（每周2-3条）

v1阶段唯一的主动内容运营，也是分享码/教学裂变的流量源：

| 内容类型 | 示例 | 裂变入口 |
|---|---|---|
| 训练计划分享 | "我的5分化力量计划，评论扣1发分享码" | 分享码FITT-XXXXXX |
| 教学内容分享 | "罗马尼亚硬拉3个常见错误" | 教学分享卡片+邀请码 |
| 数据展示 | "用FitTrack记录了30天训练，雷达图一目了然" | 软性植入 |
| 差异化 | "为什么我不用Keep了——纯本地无广告健身APP" | 品牌定位 |

运营节奏：
- 每周2-3条，日均运营≤30分钟
- 评论区"扣1发码"自动化：用户评论→私信发分享码+邀请码
- 关注"鸿蒙健身""无广告APP"等话题标签

### 2.4 教学裂变获客

v1核心裂变引擎，通过教学信息驱动用户邀请：

```
用户A解锁进阶动作教学 → 生成教学分享卡片（带邀请码FIT-INV-XXXXXX）
→ 发布到小红书/朋友圈/微信群
→ 用户B看到卡片 → 下载APP → 输入邀请码
→ A解锁3个进阶教学 + B获得7天高级统计体验
→ B训练7天后，A再解锁1个专题包
```

关键指标：邀请码激活率≥15%、K因子≥1.1

### 2.5 冷启动种子用户（前100人）

不靠ASO，靠精准触达：

| 渠道 | 方式 | 预期 |
|---|---|---|
| 健身社群/贴吧 | "做了个纯本地无广告的健身记录APP，求测试" | 30-50人 |
| 知乎健身话题 | 回答"有什么好的健身记录APP"类问题 | 20-30人 |
| 鸿蒙开发者社区 | "鸿蒙原生健身APP"技术+产品双角度 | 20-30人 |

## 三、留存机制

### 3.1 留存钩子矩阵

| 钩子 | 触发频率 | 目标指标 |
|---|---|---|
| 虚拟对手PK | 每周 | DAU/MAU +8-12% |
| 新手7天留存链 | Day1-30 | 次日留存+10%，7日留存+15% |
| 训练资产卡 | 每次打开 | 卸载率-15% |
| 计划进度链+中断补救 | 持续 | 7日留存+10% |
| 训练彩蛋 | 每次训练（20%概率） | 完成率+8% |
| 高级统计 | 每周复盘 | 主动打开率+15% |
| 推送召回 | 按策略 | DAU +5-8% |

### 3.2 留存验证重点

v1阶段需重点观察的数据：

| 数据点 | 观察目的 | 达标线 |
|---|---|---|
| 虚拟对手参与率 | 验证粘性机制 | ≥40%用户查看PK页面 |
| 高级统计使用率 | 为v2付费铺垫 | ≥30%用户每周查看 |
| 教学解锁后使用率 | 验证教学内容价值 | ≥50%解锁后查看 |
| 分享码导入率 | 验证UGC裂变 | ≥5%新用户输入 |
| 训练彩蛋触发后分享率 | 验证可变奖励 | ≥10%触发后分享 |

## 四、广告策略（克制版）

### 4.1 核心原则

> **广告 = 用户主动选择换取价值，而非被动打扰。**

### 4.2 广告位（仅2个）

| 广告位 | 触发 | 用户获得 |
|---|---|---|
| 训练完成详细报告 | 用户主动点击 | 详细肌群分析、疲劳度报告 |
| 高级报告单次体验 | 用户主动点击 | 1次高级统计图表深度查看 |

> 裂变累计3人激活后，训练报告广告位永久消失（转为裂变激励）。

### 4.3 删除的广告位

- 开屏广告（第一印象差）
- 组间休息banner（干扰核心流程）
- 设置页广告（无意义）

### 4.4 广告收入预期

| DAU | 日均展示 | eCPM | 月收入 |
|-----|---------|------|--------|
| 150 | 10-20次 | ¥18 | ¥5-10 |
| 500 | 30-60次 | ¥20 | ¥180-360 |
| 1,000 | 60-120次 | ¥22 | ¥400-800 |

> v1广告收入仅作"防零收入"，不作为盈利目标。eCPM按HarmonyOS实际预估偏低。
