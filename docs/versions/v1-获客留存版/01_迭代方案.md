## 一、版本定位

### 1.1 一句话定位

> **v1 = 零付费墙的获客与留存验证阶段。全免费开放，用"无打扰纯本地"差异化获客，用深钩子验证留存。**

### 1.2 核心策略

| 策略 | 说明 |
|------|------|
| 全免费 | 无 Pro、无订阅、无付费墙。用户零摩擦进入 |
| 深留存钩子 | 虚拟对手 + 教学裂变 + 数据沉淀锚点 + 7天留存链 |
| 克制广告 | 仅2个激励视频位，用户主动触发，不打断训练 |
| 获客驱动 | HarmonyOS原生红利 + ASO + 教学裂变 + 小红书内容 |
| 已实现不启用 | Pro/兑换码已在Phase 2编码实现，v1不启用，后续版本直接开关拨通 |

### 1.3 与原方案的关键差异

| 维度 | 原运营优化方案 | v1 获客留存版 |
|------|--------------|--------------|
| Pro体系 | 开放（月卡/年卡/终身+试用） | 不开放，全免费 |
| 历史记录限制 | 7天查看限制 | 不限制，全免费可查 |
| 高级统计 | Pro专属 | 全免费开放 |
| 裂变激励 | Pro时长激励 | 功能解锁（教学信息）+ 虚拟荣誉 |
| 付费转化 | v1即开始 | v1不转化，v2启动 |
| 广告位 | 2个激励视频 | 2个激励视频（保留，但"Pro试用延长"改为"看广告得1次高级报告"） |

### 1.4 现有基线（Phase 1 + Phase 2 已完成功能）

以下功能已上线，v1在此基础上叠加：

## 二、v1 新增核心功能

### 2.1 虚拟对手——解决单机无社交的粘性短板

预埋300+虚拟用户训练数据，按真实日历时间独立演进（不依赖用户训练事件），让用户有"和真人PK"的感觉。

核心改进（相比原方案）：
- 对手按日历时间独立推进，用户不开APP对手也在"练"
- 扩到300+对手，每周匹配池轮换
- 引入对手叙事（人设+偶尔动态"今天加班没练"）
- 胜负分布真实化：有碾压局、胶着局、被吊打局，不是永远5-15%差距
- 冷启动匹配：新手引导时问"你每周打算练几次？"，按回答初始化匹配层

### 2.2 教学信息系统——裂变核心驱动力

健身用户刚需痛点：不知道动作怎么做。

内容结构：
- 基础教学（免费）：50个基础动作·图文要点
- 进阶教学（裂变解锁）：每邀请1人激活→解锁3个进阶动作（含动图/常见错误/替代动作）
- 专题教学包（裂变里程碑）：累计邀请3人→解锁"卧推完全指南"专题
- 高手教学（裂变里程碑）：累计邀请5人→解锁"渐进超负荷实操"专题

关键设计：
- 教学信息永久解锁，不收回
- 教学可分享→生成分享卡片带邀请码
- 教学带虚拟教练人设署名

### 2.3 教学裂变体系——v1获客引擎

邀请码复用现有HMAC本地验证机制（与兑换码独立密钥）：

- 邀请码格式：FIT-INV-XXXXXX（6位，独立前缀）
- 与分享码FITT-XXXXXX区分（UGC内容，不含权益）
- 激活时机：首启新手引导末尾 / 设置页"我有邀请码"入口

激励分层（全永久解锁，不收回）：

| 被邀请人行为 | 邀请人获得 | 被邀请人获得 |
|---|---|---|
| 激活（输入邀请码+首次训练） | 解锁3个进阶动作教学 + "引路人"徽章 | 7天高级统计全开放体验 |
| 7日留存 | 解锁1个专题教学包 | — |
| 累计邀请3人激活 | 永久免广告看训练报告 + "布道者"徽章 | — |
| 累计邀请5人激活 | 解锁高手教学专题 + 专属虚拟对手皮肤 | — |
| 累计邀请10人激活 | "燃力大使"永久称号 | — |

反作弊：
- HMAC校验邀请人ID≠被邀请人ID（防自邀）
- 一码一绑，激活后不可改
- 单机版无法防多设备刷量，接受损耗（联网版用设备指纹根治）

### 2.4 高级统计全免费开放

v1阶段全部免费，目的：
- 验证留存数据最干净
- 用户用惯了高级分析，v2收费时"失去感"最强
- 包含：肌群雷达图、渐进负荷曲线、PR突破日历、热力图升级（频次+强度+PR标记）

### 2.5 训练彩蛋（可变奖励）

每次训练完成后20%概率触发彩蛋：里程碑/PR突破/连续打卡/总量里程碑/肌群平衡。
可分享，制造"今天有惊喜"的期待。

### 2.6 新手7天留存链

```
Day 1：新手引导 + 首次训练记录（B1已完成）
Day 2：推送"昨天的训练数据已保存，今天试试背部？"（基于Day1部位推荐拮抗肌群）
Day 4：若未训练，温和引导"休息一下也不错，看看你的训练日历"
Day 7：弹窗"你已经用FitTrack一周了，这是你的第一份周报"
Day 14：推送"你的训练日历已有14个方块"
Day 30：首页弹窗"月度进步快照"（与Day1对比）
```

通知权限策略：在"创建第一个训练计划"后请求（价值已建立时），不冷启动弹。

### 2.7 训练资产卡 + 计划进度链

- 首页训练资产卡片：累计训练天数/总重量/连续打卡/本周PK
- 计划进度链：进度条+预计完成+下次训练提示
- 中断补救：≥3天温和引导，≥7天调整文案，≥15天不主动打扰

### 2.8 推送策略重构

| 用户状态 | 推送时机 | 文案 | 频次上限 |
|---|---|---|---|
| 训练日前一晚 | 21:00（可配） | "明天是你的训练日，早点休息" | 周1次 |
| 训练日当天 | 用户配置时间 | "今天是你的训练日，准备好了吗？" | 周1次 |
| 中断3天 | 第4天上午 | "休息几天了，今天轻松练一下？" | 总1次 |
| 中断7天 | 第11天 | "你的训练日历还有X个方块，别让它断了" | 总1次 |
| 中断15天 | 停止推送 | — | — |
| 7天全勤 | 当日训练后 | "7天全勤！超越了85%的用户" | 周1次 |
| 全局限制 | — | — | 7天≤3次 |

## 三、阶段目标与验证阈值

### 3.1 v1 达标才启动 v1.5

| 指标 | 达标阈值 | 说明 |
|---|---|---|
| 7日留存 | ≥25% | 健身类优秀线 |
| DAU/MAU | ≥30% | 粘性验证 |
| 累计用户 | ≥3,000 | 有足够基数 |
| 周均新用户 | ≥200 | 获客引擎跑通 |
| 裂变K因子 | ≥1.1 | 裂变机制有效 |

### 3.2 未达标怎么办

- 7日留存<25%：优先优化新手引导和虚拟对手
- K因子<1.1：优先优化教学裂变激励和分享卡片
- 累计用户<3000：优先加大小红书内容和ASO优化
