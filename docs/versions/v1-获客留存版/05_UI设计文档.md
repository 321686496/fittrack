## 第1章 设计哲学与原则

### 1.1 产品定位

FitTrack 是一款力量训练垂直领域的单机版健身训练计划与记录工具。v1 版本定位为"零付费墙的获客与留存验证阶段"，以"无打扰纯本地"作为差异化获客策略，全免费开放，通过虚拟对手系统、教学裂变体系、训练彩蛋等机制驱动获客与留存。

### 1.2 设计理念

| 理念 | 说明 |
|------|------|
| 无打扰纯本地 | 无服务器依赖、无强制注册、无付费墙，用户隐私优先 |
| 力量训练垂直 | 聚焦重量/组数/PR 等力量训练核心数据，不做泛运动 |
| 获客留存导向 | 每个 UI 触点都承担传播或留存的职能 |
| 数据驱动激励 | 通过趣味类比、PK 对比、徽章成就激发持续训练动力 |

### 1.3 四大设计原则

1. **信息层级清晰** — 每个页面从上到下、从左到右按重要性递减排列，核心数据优先呈现，次要信息折叠或置于次级页面
2. **视觉一致性** — 全局通过 `FitTrackColors` ThemeExtension 统一色板，禁止硬编码颜色；组件复用优先于自定义
3. **即时反馈** — 用户操作后 ≤300ms 内给出视觉/触觉反馈；训练保存 ≤500ms 完成；加载状态必须有占位
4. **无障碍包容** — 支持大字模式（silver-care 主题）、高对比度、≥44pt 触控目标、Phosphor Icons 矢量图标

### 1.4 目标用户画像

| 维度 | 描述 |
|------|------|
| 核心用户 | 18-40 岁力量训练爱好者，每周训练 3-5 次 |
| 痛点 | 现有 APP 过度商业化、付费墙频繁、社交压力过大 |
| 场景 | 健身房训练时单手操作、组间休息快速记录、训练后查看统计 |
| 期望 | 快速记录、清晰反馈、持续激励、无打扰 |

### 1.5 图标规范

- **图标库**：统一使用 Phosphor Icons 矢量图标库
- **禁用 emoji**：页面内功能图标禁止使用 emoji 字符（主题选择器展示用 emoji 为过渡方案，后续版本替换为 Phosphor Icons）
- **SVG 优先**：自定义图形使用 SVG 绘制，保证多尺寸清晰
- **触控目标**：最小 44×44pt，间距 ≥8px

## 第2章 设计令牌系统

### 2.1 FitTrackColors ThemeExtension

所有 UI 颜色通过 `Theme.of(context).extension<FitTrackColors>()!` 访问，**禁止硬编码颜色值**。

```dart
final colors = Theme.of(context).extension<FitTrackColors>()!;
colors.bgCard;       // 卡片背景
colors.accentGlow;   // 主强调色
colors.textPrimary;  // 主文本色
```

#### 13 个 Color 字段定义

| 字段名 | 语义 | 用途 |
|--------|------|------|
| `bgSecondary` | 次级背景 | 页面次级区域、输入框填充 |
| `bgCard` | 卡片背景 | 卡片、弹窗、浮层背景 |
| `bgElevated` | 提升背景 | 底部导航栏、悬浮元素 |
| `accentGlow` | 主强调色 | 按钮、选中态、进度条填充 |
| `accentSecondary` | 辅助强调 | 渐变第二色、次级按钮 |
| `textPrimary` | 主文本 | 标题、正文主体 |
| `textSecondary` | 次级文本 | 说明文字、副标题 |
| `textMuted` | 弱化文本 | 占位符、时间戳、提示 |
| `borderColor` | 边框色 | 卡片边框、分割线 |
| `successColor` | 成功色 | 完成状态、正向指标 |
| `warningColor` | 警告色 | 提醒、注意 |
| `infoColor` | 信息色 | 链接、信息标签 |
| `purpleColor` | 紫色标签 | 特殊徽章、PR 标记 |

### 2.2 字体系统

基于 Material TextTheme 13 档，核心使用规格如下：

| 语义 | TextTheme 档位 | 字号 | 字重 | 字间距 | 用途 |
|------|---------------|------|------|--------|------|
| 大标题 | displayLarge | 32 | w800 | 0.5 | 启动页、年度报告标题 |
| 标题 | headlineMedium | 24 | w700 | 0.5 | 页面主标题 |
| 小标题 | titleLarge | 20 | w800 | 0.5 | 卡片标题、区块标题 |
| 副标题 | titleMedium | 16 | w700 | - | 列表项标题 |
| 小标签 | titleSmall | 14 | w600 | - | 次级标签 |
| 正文 | bodyLarge | 16 | w400 | - | 主体内容 |
| 说明 | bodyMedium | 14 | w400 | - | 说明文字 |
| 辅助 | bodySmall | 12 | w400 | - | 时间戳、备注 |

**字体族**：系统默认无衬线字体（iOS: San Francisco / Android: Roboto），中文回退到思源黑体。

### 2.3 间距系统

基准单位 4px，采用 4/8/16/24/32 五档：

| 令牌 | 值 | 用途 |
|------|----|------|
| `space-xs` | 4 | 图标与文字间距、紧凑元素内间距 |
| `space-sm` | 8 | 组件内间距、列表项间距 |
| `space-md` | 16 | 卡片内间距、区块间距 |
| `space-lg` | 24 | 卡片间间距、页面水平边距（紧凑模式） |
| `space-xl` | 32 | 区块间大间距、页面顶部间距 |

**页面水平边距**：默认 18px（代码现状），新增页面建议统一为 24px（紧凑模式标准）。

### 2.4 圆角系统

| 令牌 | 值 | 用途 |
|------|----|------|
| `radius-sm` | 8 | 小按钮、标签、徽章 |
| `radius-md` | 12 | 输入框、小卡片 |
| `radius-lg` | 16 | 中型卡片、弹窗 |
| `radius-xl` | 20 | 主卡片（CardWidget 默认） |
| `radius-2xl` | 24 | 大型容器、底部弹窗顶部 |
| `radius-full` | 50 | 按钮（胶囊形）、底部导航栏（102） |

### 2.5 阴影与海拔系统

| 层级 | elevation | 阴影规格 | 用途 |
|------|-----------|---------|------|
| 0 | 0 | 无阴影 | 平面卡片（CardWidget 默认 elevation: 0） |
| 1 | 0 + 边框 | 1px borderColor | 卡片（边框替代阴影） |
| 2 | 双重阴影 | black 25%/blur 20/offset(0,6) + accentGlow 8%/blur 30 | 底部导航栏 |
| 3 | 标准 | Material elevation 3 | 弹窗、浮层 |

### 2.6 动效令牌

| 令牌 | 值 | 用途 |
|------|----|------|
| `duration-fast` | 150ms | 按钮按压、选中态切换 |
| `duration-normal` | 300ms | 主题切换、页面转场 |
| `duration-slow` | 500ms | 庆祝动画、进度条填充 |
| `curve-standard` | Curves.easeInOut | 通用动效曲线 |
| `curve-decelerate` | Curves.decelerate | 进入动效 |
| `curve-bounce` | Curves.elasticOut | 庆祝/彩蛋动效 |

### 2.7 热力图色值规范

训练日历热力图使用固定 5 级色值，不随主题变化：

| 等级 | 色值 | 条件 | 说明 |
|------|------|------|------|
| L0 | `#EBEEF0` | 无训练 | 空白格 |
| L1 | `#BBDEFB` | <30min | 轻量训练 |
| L2 | `#42A5F5` | 30-60min | 标准训练 |
| L3 | `#1565C0` | >60min | 充分训练 |
| L4 | `#FFD54F` | PR 日 | 突破个人记录（高光边框） |

## 第3章 主题系统

FitTrack 提供 7 套主题，覆盖不同用户偏好与使用场景。默认主题为 `vitality-sport`。

| ID | 名称 | 风格描述 | 明暗 | 主色 | 背景色 |
|----|------|---------|------|------|--------|

| `silver-care` | 长者关怀 | 大字高对比，清晰易读 | 浅色 | `#059669` | `#FFFFFF` |

### 3.5 Pro 主题限制策略

- 非 Pro 用户：仅可使用 `vitality-sport` + `fresh-minimal` 2 套主题
- Pro 用户：解锁全部 7 套主题
- 非Pro 用户点击锁定主题时，弹出 Pro 购买引导
- 主题切换页展示锁定标识（锁形图标 + "Pro" 标签）

### 3.6 主题切换机制

- 切换通过 `main.dart` 的 `onThemeChanged` 回调统一处理
- 切换动画时长 300ms，使用 `Color.lerp` 平滑过渡
- 主题选择持久化到 SharedPreferences
- 性能要求：主题切换 ≤300ms 完成

## 第5章 页面模板与布局规范

### 5.1 页面骨架结构

标准页面采用三段式骨架：

```
┌─────────────────────────────┐
│  AppBar / PageHeader        │  ← 左对齐标题，可选操作按钮
├─────────────────────────────┤
│                             │
│  Body Content               │  ← 可滚动内容区
│  (SingleChildScrollView /   │
│   ListView / CustomScrollView)│
│                             │
├─────────────────────────────┤
│  BottomNav (可选)            │  ← 悬浮胶囊，仅主导航页
└─────────────────────────────┘
```

- **主导航页**（首页/计划/统计/个人中心）：包含 BottomNav
- **功能子页**（设置/训练执行/动作详情等）：无 BottomNav，提供返回按钮
- **全屏页**（启动页/引导页/问卷）：无 AppBar 无 BottomNav

### 5.2 列表布局规范

| 场景 | 组件 | 间距 |
|------|------|------|
| 设置列表 | ListView + MenuButton | vertical 8 |
| 记录列表 | ListView + CardWidget | vertical 9（cardTheme margin） |
| 数据概览 | GridView（2 列） | spacing 12 |

### 5.3 网格布局规范

**两列卡片网格**（数据概览、徽章展示等）：

| 属性 | 规格 |
|------|------|
| 列数 | 2 |
| 水平间距 | 12 |
| 垂直间距 | 12 |
| 页面边距 | 24（紧凑模式） |
| 卡片内间距 | 16 |

### 5.4 空状态规范

```
┌─────────────────────────────┐
│                             │
│         [图标 64px]          │
│                             │
│      暂无训练记录             │
│   完成首次训练后这里会显示      │
│                             │
│      [开始训练]              │
│                             │
└─────────────────────────────┘
```

## 第9章 适配与性能规范

### 9.1 屏幕适配

| 属性 | 规格 |
|------|------|
| 基准 | Material Design 响应式布局 |
| 单位 | 逻辑像素（dp），禁止使用物理像素 |
| 最小宽度 | 320dp（iPhone SE） |
| 推荐宽度 | 375-414dp（主流机型） |
| 大屏 | ≥600dp 时可切换双栏布局（可选） |

### 9.2 安全区域处理

- 所有页面必须使用 `SafeArea` 包裹，处理刘海屏/异形屏
- 底部导航栏使用 `SafeArea(top: false)` 仅处理底部安全区
- 全屏页面（启动页/引导页）可忽略 SafeArea，但内容需避开传感器区域

### 9.3 暗色模式适配

- 深色主题（iron-forge / neon-cyber / black-gold）使用 `Brightness.dark`
- 所有颜色通过 `FitTrackColors` 获取，禁止硬编码
- 图片/图标在深色模式下需提供适配版本或调整透明度
- 阴影在深色模式下减弱（黑色阴影不可见）

### 9.4 无障碍规范

| 项目 | 要求 |
|------|------|
| 对比度 | 文字与背景对比度 ≥4.5:1（WCAG AA） |
| 触控目标 | 最小 44×44pt |
| 字体缩放 | 支持系统字体缩放，最大 1.5x |
| 语义标签 | 所有交互元素提供 Semantics 标签 |
| 长者关怀 | silver-care 主题默认放大字号 + 高对比度 |

### 9.5 图标规范

- **图标库**：Phosphor Icons（Flutter 包）
- **自定义图标**：SVG 格式，多尺寸适配
- **尺寸**：Tab 栏 24、列表 20、按钮 18、标签 16
- **颜色**：跟随主题 `accentGlow` / `textMuted`
- **禁用 emoji**：功能图标禁止使用 emoji 字符

### 9.6 图片规范

- **训练动作图**：动图（GIF/WebP）优先，静态图为辅
- **占位图**：加载中显示 shimmer 或灰底
- **缓存**：图片缓存上限按设备内存动态调整
- **分享卡片**：1080×1920 高清输出

### 9.7 数据限制与缓存

| 数据类型 | 上限 | 说明 |
|---------|------|------|
| 训练记录缓存 | 500 条 | 超出按时间淘汰 |
| 身体数据历史 | 50 条 | 超出按时间淘汰 |
| 周数据保留 | 12 周 | 超出自动归档 |
