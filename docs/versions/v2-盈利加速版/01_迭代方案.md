# FitTrack 燃力 v2 盈利加速版 迭代方案

> 版本：v2.2 | 更新日期：2026-07-16 | 文档状态：调优版
> 前置条件：v1.5 过渡验证版达标（智能推荐≥40%、疲劳度≥30%、adgate≥25%、累计≥5000）

## 一、版本定位

### 1.1 一句话定位

> **v2 = 在已验证需求和用户基数上，启动 Pro 订阅 + Pro 时长裂变，实现盈利加速。基础版功能保留解锁路径，增强版 Pro 专属，老用户平滑过渡。**

### 1.2 核心策略

| 策略 | 说明 |
|------|------|
| Pro订阅启动 | 月卡/季卡/年卡/终身四档 + 14天试用 |
| 增强版驱动付费 | 智能推荐/疲劳度/编排增强版 Pro 专属，基础版保留解锁路径 |
| 老用户保护 | grandfathering 策略，折扣价 + 数据贡献送 Pro |
| 裂变升级 | 教学功能解锁升级为 Pro 时长裂变，180天上限防白嫖 |
| 收入双引擎 | Pro 订阅（主力65%）+ 解锁收入（补充25%）+ 兑换码（获客10%） |
| 历史记录策略 | 不锁查看，锁深度分析（月度/年度报告 Pro 专属） |
| Pro体验卡 | 老用户邀请新用户注册即得3天Pro体验，先体验后付费 |
| 降级通道 | Pro到期后引导至解锁路径，而非直接锁功能逼走用户 |

> **调优说明**：
> - 新增**季卡档位**（¥15/季），填补月卡（¥9.9）和年卡（¥38）之间的价格gap，给用户提供第三个选择
> - 新增**Pro体验卡**机制：老用户邀请新用户注册后，老用户获得3天Pro体验（非裂变权益），让老用户先体验增强版再决定付费
> - 新增**降级通道**设计：Pro到期后若不想续费，提供"看一段小视频继续使用1次"的解锁选项，而非直接锁功能逼走用户

首发期运营（调优为**限量**策略）：
- 年卡首发价¥18（前200名），制造稀缺感且避免长期低价锚
- 锚点展示："终身¥68（划线）→ 年卡¥38 → 首发¥18（限前200名）"
- 200名用完后恢复¥38年卡常规价

> **调优说明**：原方案"限时30天¥18"会建立低价锚——用户会等下一个"限时优惠"。调优后为"限量前200名"，用完即恢复原价，用户无法预期"下次还会便宜"。同时新增季卡档位（¥15），为不愿付月卡但又觉得年卡太贵的用户提供中间选项。

### 2.2 14天Pro试用

新用户首启后自动获得14天Pro全功能试用：

```
试用期内：所有Pro功能开放，顶部常驻"试用剩余X天"
试用结束前2天：推送"你的Pro试用后天结束，年卡限时¥18"
试用结束：Pro功能锁定，保留试用期内生成的数据（让用户看到失去的东西）
```

14天设计的理由：健身是周周期，14天覆盖两个完整训练周+周报+虚拟对手PK，转化触发点充分。

### 3.1 问题

v1/v1.5 用户习惯全免费，v2 加付费墙会反弹。

### 3.2 策略：折扣价 + 数据贡献送 Pro + Pro体验卡

| 老用户类型 | 转换策略 | 说明 |
|---|---|---|
| 训练≥30天的用户 | 年卡限时¥19（新用户¥38） | 50%折扣，限时30天 |
| 训练≥90天的用户 | 额外赠送3个月Pro | 数据贡献大，感恩回馈 |
| 训练≥180天的用户 | 额外赠送6个月Pro | 核心用户，重点保护 |

| 所有老用户 | 智能推荐/疲劳度基础版仍可解锁使用 | 不降级已有功能 |
| **所有老用户（新增）** | **邀请新用户注册即得3天Pro体验** | **调优新增**让老用户先体验增强版再决定付费 |

> - 老用户邀请新用户注册（无需新用户完成训练），老用户立即获得3天Pro体验

> - 目的：让老用户先"尝鲜"增强版功能（智能推荐增强版、疲劳度增强版等），体验后再决定付费，降低决策门槛

## 四、Pro 时长裂变体系

### 4.1 核心理念

> **Pro 时长是"体验放大器"不是"权益替代品"。**

三条铁律：
1. 年获取上限180天——永远凑不满一年，重度用户必须付费补差
2. 按行为解锁——绑定被邀请人激活/留存/付费三段
3. 节奏控制——激励分多次发放，制造"差一点到账"的期待

### 4.2 邀请码技术机制

复用 v1 教学裂变的 HMAC 验证框架：
- 格式：FIT-INV-XXXXXX（与 v1 相同）
- v2 激活后同时触发教学解锁（v1遗留）+ Pro时长激励（v2新增）

### 4.3 双向激励结构

| 被邀请人行为 | 邀请人获得 | 被邀请人获得 |
|---|---|---|
| 激活（输入邀请码+首次训练） | 3天Pro + "引路人"徽章 + 3个进阶教学 | 14天Pro试用（叠加） |
| 7日留存 | 7天Pro | — |
| 首次付费Pro | 30天Pro | — |

### 4.4 防白嫖机制

| 机制 | 说明 |
|---|---|
| 年上限180天 | 邀请得来的Pro累计每年封顶180天 |
| 到期不连发 | 激励Pro到期后不自动续，需新邀请触发 |
| 不可转赠 | 仅限邀请人本人账号 |
| 临近上限转化 | 累计达150天时推送"年卡¥38直接补满一整年" |

### 4.5 里程碑体系

| 里程碑 | 解锁 |
|---|
| 邀请1人激活 | 3天Pro + "引路人"徽章 |
| 累计3人留存7日 | 30天Pro + "布道者"徽章 |
| 邀请1人首次付费 | 30天Pro + "金牌教练"称号 |
| 累计5人付费 | 90天Pro + 专属虚拟对手皮肤 |
| 累计10人付费 | "燃力大使"永久称号 |

### 4.6 与 v1/v1.5 裂变的衔接

v1 用户的邀请数据在 v2 自动迁移：
- v1 累计邀请数→v2 继续累计
- v1 已解锁的教学/徽章→永久保留
- v1.5 服务端存储的邀请关系→直接复用到 v2 完整服务端
- v1.5 轻服务器层（裂变验证+内容分发）→升级为 v2 完整服务端（用户系统+Pro验证+UGC+排行榜）
- v1 新增的邀请→同时触发 v1 教学解锁 + v2 Pro时长

> v1.2/v1.5.2调优说明：v1.5已引入轻服务器层，v2可直接升级而非从零建设服务器架构。

## 五、兑换码返券分销

### 5.1 模式

原方案现金佣金不可持续，改为零现金流出：
- KOC不拿现金，拿"等值Pro兑换码"自用或转赠
- 每月给活跃KOC发放3-5个年卡兑换码（成本=0）
- KOC转赠给粉丝→体验后部分转化终身卡

### 5.2 技术实现

复用 v1 预埋的 HMAC 验证 + 多密钥轮换：
- 兑换码格式：FIT-RED-XXXXXXXX（8位，独立前缀）
- 本地 HMAC-SHA256 验证
- 季度密钥轮换
- 支持批量生成（开发者工具）

### 7.2 收入结构目标

| 收入来源 | 占比 | 说明 |
|---------|------|------|
| Pro订阅 | 60-70% | 主力收入 |
| 解锁收入 | 20-25% | 补充收入 |
| 兑换码 | 10-15% | 获客工具（返券模式） |

### 7.3 降级通道设计

> **调优新增**：Pro到期后若不想续费，提供"看一段小视频继续使用1次"的解锁选项，而非直接锁功能逼走用户。

Pro到期后用户路径：
```
Pro到期 → 弹窗提示"你的Pro已到期"
         → 选项A：续费Pro（年卡¥38/季卡¥15/月卡¥9.9）
         → 选项B：看15秒小视频，继续使用智能推荐增强版1次
         → 选项C：恢复免费版（基础功能永久免费，解锁路径保留）
```

> **降级通道的作用**：
> - 用户不会因为"突然不能用"而愤怒卸载
> - 解锁路径让用户体验到增强版的价值后，仍有机会回来付费
> - 保留"基础功能永久免费"的底线，维护品牌口碑

### 7.4 联网版衔接

| v2单机实现 | 联网版升级路径 |
|---|---|
| 虚拟对手 | 真实用户排行榜 |
| Pro本地验证 | 服务器验证（防多设备） |
| 训练计划分享码 | UGC计划库+推荐算法 |
| 兑换码本地验证 | 服务器验证 |
| Pro时长裂变 | 服务器设备指纹防刷 |
| 匿名统计（默认关） | 匿名埋点上传 |
| v1.5轻服务器层 | 完整服务端（用户系统+社交+排行榜+UGC） |

v2 验证核心指标达标后可启动联网版：Pro转化率≥4%、DAU/MAU≥35%、7日留存≥30%。

> **调优补充——联网版迁移预告**：
> - v2末期（达标后启动联网版开发时）建议开始预告"FitTrack联网版正在开发，你的训练数据可无缝迁移"
> - 让用户有心理预期，避免联网版上线时用户感觉"突然要上传数据"
> - 强调"核心训练数据仍可选择纯本地存储"，维护"隐私优先"的品牌承诺
> - v1.5已引入轻服务器层（邀请关系+激励记录），用户已适应"部分数据上云"，联网版迁移阻力更小
