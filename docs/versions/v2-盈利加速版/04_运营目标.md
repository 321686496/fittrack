## 一、运营总目标

> **v2 运营核心 = Pro付费转化 + 收入加速 + 裂变升级。从"广告依赖"转向"订阅驱动"。**

| 指标 | v2 目标 | 说明 |
|---|---|---|
| Pro转化率（试用→付费） | ≥15% | 14天试用深度体验后转化 |
| Pro转化率（全体用户） | 4-6% | 行业优秀线 |
| 老用户Pro转化 | 8-12% | grandfathering策略驱动 |
| 裂变K因子 | ≥1.2 | Pro时长裂变升级 |
| 月收入（DAU 3000） | ¥5,000-9,000 | Pro为主+广告补充 |
| 老用户差评率 | <3% | grandfathering保护 |
| 7日留存 | ≥25% | 不低于v1.5 |

## 二、付费转化策略

### 2.1 14天试用转化漏斗

```
新用户注册 → 14天Pro全功能试用
     ↓
Day 1-3：体验智能推荐增强版（每次训练都触发）
Day 4-7：体验疲劳度增强版 + 虚拟对手PK
Day 8-10：体验深度分析报告（月报）
Day 11-13：推送"试用后天结束，年卡限时¥18"
Day 14：试用结束→Pro锁定→保留数据→"看到失去的东西"
     ↓
转化点：年卡¥18（首发限时）/ 年卡¥38（常规）
```

### 2.2 付费触发点设计

| 触发点 | 时机 | 文案 |
|---|---|---|
| 试用结束弹窗 | Day 14 | "你的Pro试用已结束。年卡限时¥18，继续享受智能推荐等专业功能" |
| 深度报告锁定 | 用户点击月报 | "升级Pro查看完整月度报告" |
| 智能推荐锁定 | 用户训练时 | "升级Pro获取多周趋势智能推荐" |
| 裂变上限提示 | 累计150天 | "你已通过邀请获得150天Pro，年卡¥38直接补满一整年" |
| 广告厌倦点 | 用户第5次看adgate | "升级Pro，告别所有广告" |

### 2.3 定价锚点策略

```
终身¥68（划线）← 高锚点
年卡¥38 ← 主推
年卡限时¥18（首发）← 促转化
月卡¥9.9 ← 降低尝试门槛
```

展示方式："终身¥68 ~~原价~~ → 年卡限时¥18（前200名）"

## 六、广告运营（v2）

### 6.1 广告策略调整

v2 的广告策略从"收入来源"变为"Pro转化催化剂"：
- 免费用户看到adgate→"升级Pro免广告"
- Pro用户完全无广告（连入口都不显示）
- 广告收入是Pro收入的补充，不是主力

### 6.2 广告收入预期

| DAU | 免费用户比例 | 日均adgate | eCPM | 月广告收入 |
|-----|----------|---------|------|----------|
| 3,000 | 95% | 150-300次 | ¥22 | ¥990-1,980 |
| 5,000 | 90% | 250-500次 | ¥22 | ¥1,650-3,300 |
| 8,000 | 85% | 400-800次 | ¥22 | ¥2,640-5,280 |

> 随Pro用户比例提升，广告收入占比下降，但Pro收入增长更快，总收入提升。
