# FitTrack 燃力 v2 盈利加速版 运营目标

> 版本：v2.2 | 更新日期：2026-07-16 | 文档状态：调优版

---

## 一、运营总目标

> **v2 运营核心 = Pro付费转化 + 收入加速 + 裂变升级。从"解锁依赖"转向"订阅驱动"。**

| 指标 | v2 最低目标 | v2 理想目标 | 说明 |
|---|---|---|---|
| Pro转化率（试用→付费） | ≥8% | ≥15% | 14天试用深度体验后转化（调优说明：工具类APP平均5-12%） |
| Pro转化率（全体用户） | 3-5% | 4-6% | 健身APP行业Pro转化率约2-5%（调优说明：原方案4-6%偏乐观） |
| 老用户Pro转化 | 8-12% | 8-12% | grandfathering策略驱动 |
| 裂变K因子 | ≥1.2 | ≥1.2 | Pro时长裂变升级 |
| 月收入（DAU 3000） | ¥4,000-7,000 | ¥5,000-9,000 | Pro为主+解锁补充（调优说明：原方案下限¥5,000偏乐观） |
| 老用户差评率 | <3% | <3% | grandfathering保护 |
| 7日留存 | ≥25% | ≥25% | 不低于v1.5 |

## 二、付费转化策略

### 2.1 14天试用转化漏斗

```
新用户注册 → 14天Pro全功能试用
     ↓
Day 1-3：体验智能推荐增强版（每次训练都触发）
Day 4-7：体验疲劳度增强版 + 虚拟对手PK
Day 8-10：体验深度分析报告（月报）
Day 11-13：推送"试用后天结束，年卡首发¥18（限前200名）"
Day 14：试用结束→Pro锁定→保留数据→"看到失去的东西"
     ↓
转化点：年卡¥18（首发限量前200名）/ 季卡¥15 / 年卡¥38（常规）
```

### 2.2 付费触发点设计

| 触发点 | 时机 | 文案 |
|---|---|---|
| 试用结束弹窗 | Day 14 | "你的Pro试用已结束。年卡首发¥18（限前200名），继续享受智能推荐等专业功能" |
| 深度报告锁定 | 用户点击月报 | "升级Pro查看完整月度报告" |
| 智能推荐锁定 | 用户训练时 | "升级Pro获取多周趋势智能推荐" |
| 裂变上限提示 | 累计150天 | "你已通过邀请获得150天Pro，年卡¥38直接补满一整年" |
| 解锁厌倦点 | 用户第5次看解锁内容 | "升级Pro，告别所有解锁" |

### 2.3 定价锚点策略

```
终身¥68（划线）← 高锚点
年卡¥38 ← 主推
季卡¥15 ← 填补月卡和年卡gap（调优新增）
年卡首发¥18（前200名限量）← 促转化（调优说明：限量优于限时）
月卡¥9.9 ← 降低尝试门槛
```

展示方式："终身¥68 ~~原价~~ → 年卡¥38 → 季卡¥15 → 年卡首发¥18（限前200名）"

## 三、Pro时长裂变运营

### 3.1 裂变漏斗

```

     ↓
B训练7天留存 → A得7天Pro
     ↓
B首次付费Pro → A得30天Pro + "金牌教练"称号
     ↓
A累计150天 → 推送"年卡¥38补满一整年"
     ↓
A付费 → 从"白嫖用户"转为"付费用户"
```

## 五、老用户转化运营

### 5.1 转化策略

| 老用户类型 | 优惠 | 预期转化率 |
|---|---|---|
| 训练≥180天 | 6个月Pro赠送 + 年卡¥19 | 15-20% |
| 训练≥90天 | 3个月Pro赠送 + 年卡¥19 | 10-15% |
| 训练≥30天 | 年卡¥19（无赠送） | 5-8% |
| 训练<30天 | 无特殊优惠 | 2-3%（同新用户） |
| **所有老用户（新增）** | **邀请新用户注册即得3天Pro体验** | **先体验后付费** |

> **调优补充——Pro体验卡机制**：
> - 老用户邀请新用户注册（无需新用户完成训练），老用户立即获得3天Pro体验
> - 体验期内所有Pro功能开放，体验结束前1天推送"你的Pro体验即将结束，年卡¥19继续享受"
> - 目的：让老用户先"尝鲜"增强版功能，体验后再决定付费，降低决策门槛

### 5.2 通知节奏

```
v2上线前3天：推送"FitTrack 2.0即将到来，老用户专属福利+邀请好友得3天Pro体验"
v2上线当天：推送"2.0已上线！你的专属年卡¥19已就绪，邀请好友再得3天Pro体验"
上线后7天：推送"你的老用户优惠7天后过期"
上线后14天：推送"最后3天！年卡¥19即将恢复¥38"
```

### 5.3 已解锁权益保护

v2上线时必须确保：
- v1解锁的所有教学永久保留
- v1解锁的所有主题永久保留
- v1/v1.5所有徽章/称号永久保留
- v1邀请数据正确迁移到v2裂变体系

## 六、解锁运营（v2）

### 6.1 解锁策略调整

v2 的解锁策略从"收入来源"变为"Pro转化催化剂"：
- 免费用户看到解锁内容→"升级Pro免解锁"
- Pro用户完全无解锁（连入口都不显示）
- 解锁收入是Pro收入的补充，不是主力

### 6.2 解锁收入预期

| DAU | 免费用户比例 | 日均解锁 | eCPM | 月解锁收入 |
|-----|----------|---------|------|----------|
| 3,000 | 95% | 150-300次 | ¥22 | ¥990-1,980 |
| 5,000 | 90% | 250-500次 | ¥22 | ¥1,650-3,300 |
| 8,000 | 85% | 400-800次 | ¥22 | ¥2,640-5,280 |

> 随Pro用户比例提升，解锁收入占比下降，但Pro收入增长更快，总收入提升。
