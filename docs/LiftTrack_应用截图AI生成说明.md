# LiftTrack 应用截图 · AI 生成说明

> 用途：把本文件内容交给 AI 图像生成工具（Seedream / Midjourney / DALL·E 等）生成 6 张美观、可上架的应用市场截图。
> 原则：**一套风格、同一用户、同一训练故事**，前 3 张分别命中核心痛点（组数 / 休息 / 今日练哪）。

---

## 一、整体美术风格（所有截图必须统一，先把这个喂给 AI）

**画面版式**
- 竖版手机截图，画布比例约 9:19（推荐 1242×2688）。
- 画面分两段：**上部约 1/3 为文案区**（大标题 + 副标题，纯色/浅色卡片底），**中下部为手机 UI 画面**。
- 手机放进一只现代智能手机外框（圆角、细边框），手机屏幕内展示 App 页面真实界面；手机背后是柔和的莫兰迪色系渐变背景，无其它杂物。

**配色（莫兰迪 + 健身房活力感）**
- 画布背景：柔和低饱和渐变，如 浅灰蓝 `#EEF2F1` → 浅灰绿 `#E3EAE6`。
- 副标题文字：柔和深灰 `#5A6572`。
- 主标题文字：近黑深色 `#1F2430`，用非常粗的字重。
- 品牌主色（强调/高亮/按钮）：活力青绿 `#2BC48A`（正被训练的当前项/提示用）。
- 次要强调（鸡蛋/次要）：暖橙 `#F4A261`（彩蛋、小icon点缀）。
- 卡片底：白 `#FFFFFF`，少量圆角（12~16）、极浅阴影，符合"卡片风"。

**字体与文字**
- 中文无衬线（如苹方/思源黑体），标题字重 Black/Bold，正文 Regular。
- 主标题≥110px，副标题≈55px；App 界面内文字清晰不虚化。
- 截图内所有中文用简体；若出英文/印尼版本，仅翻译文案，版式与配色不变。

**统一人设（6 张讲同一个人的一次训练）**
- 用户：新手健身者，正在做「杠铃卧推」这一堂训练。
- 贯穿数据：动作=杠铃卧推；总组=4组，现正练**第 3 组**；重量=60kg；次数=10；组间休息=90秒；今天练=**胸部 + 三头肌**。
- 避免真实人脸/真实照片，界面用扁平图标与示意，不出现他人头像与账号。
