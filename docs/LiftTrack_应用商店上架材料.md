## 四、ASO 与搜索优化（华为重点，2026-09-26 新增）

### 4.1 华为搜索机制（先搞清楚再优化）

| 结论 | 依据 |
| --- | --- |
| 应用名称是搜索匹配第一入口，权重最高，且算法会基于名称做关键词扩展覆盖 | 官方审核指南将「应用名称」列为应用信息首要项；第三方实测权重排序为 标题 > 副标题 > 评论 > 关键词 > 小编推荐 > 简介 |
| 大陆上架后台**没有**苹果式独立关键词字段（原文档 6.5 节的「华为关键词」填写项实际不存在） | AGC 上架信息仅含名称、图标、简介、分类、标签等 |
| 补中文同义词/别名的正解是官方免费的「**搜索优化服务**」（关键词优化 + 功能标签优化） | 华为官方文档《搜索优化服务》 |
| 应用名称不得是类别词/功能性描述大词，**不得堆砌 2 个或以上关键词**，不得含特殊符号 | 官方《应用审核指南》1.2 条 |
| 名称必须与软件包内名称一致 | AGC《配置本地化基础信息》 |
| 权重侧：CPD 搜索广告 > 评论/评分 > 下载量 > 版本更新频率；**CPD 仅支持企业开发者** | 官方推广 FAQ + 第三方实测 |

## 十、风险与合规提示

1. **纯本地定位是最大卖点**：文案强调"无账号、不注册、零广告、数据只在手机里"，可显著降低苹果隐私标签与华为隐私审核压力。
2. **设备标识口径必须与文案自洽**：鸿蒙端为邀请防刷会取 OAID，因此"不收集任何数据"不能无条件写。按第八章口径统一隐私政策与苹果隐私标签，这是两端最容易被驳回的点。
3. **华为应用名称合规**：名称不得是类别词/功能性描述大词，不得堆砌 ≥2 个关键词，不得含破折号、星号等特殊符号。已定稿的「LiftTrack 健身记录」为品牌名 + 1 个功能词，边界安全；若后续想加大词，先核对《应用审核指南》1.2 条。
4. **名称修改有次数上限**（每年度 2 次）且必须与软件包内名称一致，改名与发版建议同一次完成（鸿蒙侧改 `app_name` / `EntryAbility_label`）。
5. **搜索优化服务配额有限**（关键词/标签各 2 个任务，达上限后 3 个月才能再提交），提交前务必先搜索确认未覆盖，避免浪费。
6. **鸿蒙提醒相关权限**：`PUBLISH_AGENT_REMINDER`、`VIBRATE` 是"到点提醒/振动"的核心依赖，请在权限说明与审核备注中如实、正向说明用途，避免被判定为滥用。
7. **功能与声明一致**：鸿蒙端未声明 `CAMERA`，若鸿蒙版含扫码入口须先补权限再提审；截图与简介也不要出现该端未实现的功能画面。
8. **健身/健康建议类内容**：按第八章免责声明口径处理，降低医疗类目审核风险。
9. **无账号不是缺点**：在审核备注中说明"应用可离线完整体验、无需注册"，同时准备好审核员可直接走通的付费验证路径（沙箱/内购说明），避免审核卡在"无法使用"。
