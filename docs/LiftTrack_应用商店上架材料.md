# LiftTrack 应用商店上架材料

> 面向：App Store / Google Play / 华为应用市场 / 鸿蒙应用市场 / 小米 / OPPO / vivo / 应用宝
> 版本基线：基于当前 Flutter 项目实际实现的功能撰写
> **核心定位主线：健身房训练现场最头疼的「健忘三连」——练到第几组 / 休息了多久 / 今天该练哪儿。**
> 定位语（贯穿所有渠道）：**训练交给身体，记录交给 LiftTrack。**

***

## 一、产品定位（供文案/截图统一口径）

**一句话定位**

> 一个专为**健身房训练现场**设计的训练伴侣：实时记住你练到第几组、自动帮你算休息倒计时、按计划告诉你今天该练哪个部位——**别再用脑子记训练，也别再靠纸笔。**

**核心解决的三大痛点（记住：这是主角，截图和简介必须围绕它）**

| # | 用户痛点（健身房现场的健忘）       | LiftTrack 的真实解法（已落地功能）                                          |
| - | -------------------- | --------------------------------------------------------------- |
| 1 | **练着练着就忘了现在练了几组**    | **实时训练模式**：边练边点，屏幕实时显示「第 X 组 · 重量 · 次数」，当前组高亮；中途被打断，回来还能**接着练** |
| 2 | **不知道休息够没有，坐一会儿就超时** | **自动休息倒计时**：每组结束自动开始计时，到点震动+声音提醒「该练下一组了」                        |
| 3 | **进了健身房不知道今天该练哪个部位** | **今日训练指引**：跟着科学计划走，每日/定时**锻炼提醒**告诉你今天练哪、练哪些动作                   |

**辅助卖点（第二梯队，用于补充和收尾）**

- 进步看得见：周/肌群统计、最大重量 PR、身体数据趋势

- 不会练不怕：内置计划库 + 图文动作教程 + 章节课

- 坚持有陪伴：虚拟对手陪你推进，训练彩蛋、7天养成链

- 数据只留本地：不用注册、不联网、零广告、可导出

> **文案铁律**：每一张截图、每一段简介，先讲「组数/休息/今天练哪」三件事里的至少一件，隐私和陪伴再往后放。

## 三、应用简介（重点打磨区）

### 3.1 短简介（华为/小米/OPPO/vivo 一句话,≤100字）

> 走进健身房就记不清练了几组、休息了多久、今天该练哪？LiftTrack 实时替你记组数、自动算休息倒计时、按计划提醒今天练哪个部位，练到一半被打断还能接着练。不用注册、零广告，数据全在本地。

### 3.2 长简介（App Store「描述」/ Google Play 推荐文案,300\~500字）

> **站上器械才发现：刚才第几组了？休息够了吗？今天该练哪？**
>
> 在健身房，最累的往往不是动作，而是**一边举铁一边还得用脑子记账**：这组做了几个？是第几组了？中间歇了多久？今天到底是练胸还是练腿？
>
> **LiftTrack 专门替你说的脑子干活。训练交给身体，记录交给它。**
>
> **练到第几组，一眼可见**
> 训练中实时记录：第几组、重量、次数，当前组一按就亮；不用低头翻本子，也不用事后补记。中途接电话、被打断？回来接着练，进度一点不丢。
>
> **休息多久，它帮你数**
> 每组动作结束，自动开始**休息倒计时**，到点震动提醒"该练下一组了"——再也不用盯着手机猜"我是不是歇太久了"，卡着节奏练效果更好。
>
> **今天练哪，它告诉你**
> 跟着科学计划走，LiftTrack 会在训练前提醒你今天该练哪个部位、练哪些动作；从新手全身、增肌塑形到居家零器械，计划库任你选。
>
> **加上这些，练得更踏实**
> 你问有没有进步？周训练趋势、目标肌群分布、还有最大重量 PR，数据说话；动作不会做，有图文教程；怕一个人坚持不下去，有虚拟对手陪你推进。
>
> 而这一切，**都不用注册账号、不用联网、零广告**——你的每一次训练，只存在你自己的手机里。
>
> **别再让脑子记训练了。下载 LiftTrack，从今晚练到第几组开始。** 现在就记下第一个突破。

### 3.3 关键词（国内搜索 + ASO）

> 健身 训练 增肌 减脂 塑形 深蹲 卧推 硬拉 组数 休息计时 计时器 健身记录 训练计划 打卡 锻炼提醒 今日训练 新手健身 力量训练 无氧 抗阻力（分类精排按渠道微调）

## 四、应用截图（重点打磨区）

> 采用**移动端 6 张叙事结构**（苹果/华为 6.7 英寸 & 5.5 英寸各一套）。每张 = 「一句痛点/卖点主文案 + 清晰 UI 画面」。文案放顶部 1/3，UI 放中下部，底色用主题色但不喧宾夺主。
> **前 3 张必须分别命中三大核心痛点**。

### 截图 1 —— 记不住练了几组（实时训练·Hero）

- **主文案**：`练到第几组，不用记`

- **副**：`边练边点，当前组一按高亮，第几组 / 重量 / 次数一目了然`

- **画面**：进行的训练页——大号「第 3 组」高亮卡片、动作列表（杠铃卧推 第3/4组）、正在执行的当前组醒目呈主题色、底部「完成训练」主按钮。

- **UI 元素**：当前组别数字放大做视觉锚点，一眼看懂"我现在到哪了"。

### 截图 2 —— 休息不够/太久（自动休息倒计时）

- **主文案**：`休息多久，它替你数`

- **副**：`每组结束自动倒计时，到点震动提醒「该练下一组」`

- **画面**：圆形休息倒计时环（如 65/90 秒）+「休息中·即将提醒」状态 + 下方『下一组：杠铃卧推 3×8-12』。

- **UI 元素**：把计时环做成全屏焦点，配"歇够了、要开工"的提示。

### 截图 3 —— 不知道今天练哪（今日指引·锻炼提醒）

- **主文案**：`今天练哪，它提醒你`

- **副**：`按计划告诉你今天该练哪个部位，到点还会提醒`

- **画面**：计划页 / 「今日训练」区块——显示今天要练的部位（如"胸 + 三头"）与动作清单 + 「每日锻炼提醒」开关开启。

- **UI 元素**：今日部位大标题 + 动作勾选列表，把"今天的课表"做成封面焦点。

### 截图 4 —— 练到一半被打断（中断续练·体验梗）

- **主文案**：`练到一半被打断？回来接着练`

- **副**：`训练进度自动保存，回来一键继续，进度一点不丢`

- **画面**：训练中断提示/「继续上次训练」卡片——显示"上次练到第 2 组 · 还剩 2 组"并可一键继续。

- **UI 元素**：恢复卡片上醒目的『继续』按钮 + 上次进度小结。

### 截图 5 —— 有没有进步 + 不会练（支撑）

- **主文案**：`练得对不对，数据说话`

- **副**：`周趋势、肌群分布、最大重量 PR；动作不会练，图文教程手把手教`

- **画面**：统计页（总次数/最大重量 PR + 周柱状图）+ 一张动作教程卡片叠加引导。

- **UI 元素**：PR 突破做点亮焦点，教程缩略图提示"不会就现学"。

### 截图 6 —— 隐私收尾（安心）

- **主文案**：`你的训练数据，只在你手机里`

- **副**：`不用注册 · 不用联网 · 零广告 · 可导出备份`

- **画面**：我的页/设置——「离线模式 / 免注册 / 零广告 / 数据导出」隐私徽章排布。

- **UI 元素**：四个隐私徽章做一个简洁收束，给用户一个"安心的理由"。

**截图合规提示**：按发行地区出中文/英文/印尼文各一套；UI 文字与本简介口径一致，**不得夸大（勿写"AI 教练"）**；不得出现测试数据编号、他人头像等可识别信息。

## 六、隐私 & 合规填写（务必与实现一致）

- **数据收集**：本应用**不联网、不注册、不上传任何数据**，训练/身体数据仅存本机（SQLite/SharedPreferences），提供导出备份。

- **所需权限**（按实际声明填写）：

  - 通知/本地提醒（**每日锻炼提醒**、健身卡到期、智能提醒）——iOS/Android 说明用途；

  - **相机**（扫码导入计划/邀请码）——Android `CAMERA`、iOS `NSCameraUsageDescription`，注明"用于扫描训练计划与邀请码二维码/条形码"；

  - 精确闹钟（Android 12+，定时提醒）——`SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM`；

  - 鸿蒙：本地通知+提醒、卡片能力，按鸿蒙市场模板声明。

- **年龄分级**：普遍级（4+/Everyone）。

- **账号**：无账号体系、不登录不绑机；若提供兑换码业务，注明"由运营方分发"。
