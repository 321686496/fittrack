### 1.2 Pro 兑换码体系（核心变现手段）

#### 兑换码生成 & 验证架构

```
【本地核心逻辑】—— 无服务器也可运行

兑换码格式（对称加密离线验证）：
  FITT-XXXX-XXXX-XXXX
  算法：基于 HMAC-SHA256 截断为 12 位字母数字
  密钥：预埋在代码中的常量（可通过后续更新替换）

验证流程（全本地完成，无需网络）：
  用户输入兑换码 → 本地 HMAC 校验码格式正确性
  → 验证通过后写入 SharedPreferences `redeemed_codes` 列表
  → Storage.isPremiumUser = true
```

**为什么要设计本地验证？** 因为 FitTrack 是纯单机版，没有服务器。兑换码验证必须在设备本地完成。但这意味着一旦密钥泄漏，兑换码可以被破解。所以：

```dart
// 兑换码验证核心逻辑（伪代码示意）
class RedeemService {
  // 预置多批次密钥，可通过版本更新轮换
  static const List<String> _secrets = [
    'fitTrack_secret_v1_2025',
    'fitTrack_secret_v2_2026',
  ];

  static bool verifyCode(String code) {
    // 1. 格式校验：FITT-XXXX-XXXX-XXXX
    final pattern = RegExp(r'^FITT-([A-Z0-9]{4})-([A-Z0-9]{4})-([A-Z0-9]{4})$');
    if (!pattern.hasMatch(code)) return false;

    // 2. 检查是否已被使用（本地已兑换列表）
    if (_isAlreadyRedeemed(code)) return false;

    // 3. HMAC 签名验证
    for (final secret in _secrets) {
      final expected = _generateHmac(code.substring(5), secret);
      if (code.endsWith(expected)) return true;
    }
    return false;
  }

  // 4. 记录已兑换（本地存储）
  static void markAsRedeemed(String code) {
    final list = Storage.getRedeemedCodes();
    list.add(code);
    Storage.setRedeemedCodes(list);
    Storage.setPremiumUser(true); // 解锁 Pro
  }
}
```

**批量生成兑换码脚本**（Python，可本地运行）：

```python
# generate_codes.py
import hmac
import hashlib
import random
import string

SECRET = 'fitTrack_secret_v1_2025'

def generate_code(secret):
    # 生成 8 位随机内容
    rand_part = ''.join(random.choices(string.ascii_uppercase + string.digits, k=8))
    content = f'{rand_part[:4]}-{rand_part[4:]}'
    # HMAC 签名截取 4 位
    sig = hmac.new(
        secret.encode(), content.encode(), hashlib.sha256
    ).hexdigest()[:4].upper()
    return f'FITT-{content[:4]}-{content[5:]}-{sig}'

# 批量生成 100 个
codes = [generate_code(SECRET) for _ in range(100)]
for c in codes:
    print(c)

print(f'\n总计 {len(codes)} 个兑换码已生成')
```

> **一句话总结**：
