使用步骤

  1. 从模拟器/App 截取 8 个对应页面，保存为 s1.png ~ s8.png，放到同级 screenshots/ 文件夹
  2. 浏览器打开本文件，截图会自动填入手机屏幕
  3. 点击「打印 / 另存为 PDF」，在打印对话框选择「另存为 PDF」，即可得到上架用 PDF（可用工具转 PNG）
  4. 或用浏览器截图扩展（如 GoFullPage）直接截取整页
