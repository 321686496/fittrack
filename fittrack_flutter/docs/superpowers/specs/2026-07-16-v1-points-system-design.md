> 版本：v1.0 | 日期：2026-07-16 | 状态：待实施
> 依据：v1 获客留存版迭代方案（01_迭代方案.md v1.2）

## 一、核心定位

**策略转向**：从"全免费 + 克制广告"转向"轻度变现——核心功能永远免费，高级功能走积分+双轨解锁"。

**三不原则**：
- 不挡核心闭环：训练/计划/历史记录/基础统计/基础教学/虚拟对手PK 永远免费
- 不强制看广告：积分与广告等价互换，用户自由选择
- 不破坏裂变：邀请改为积分加速器，里程碑徽章/称号全部保留

## 二、积分经济

### 2.1 获取途径

| 途径 | 积分 | 每日上限 | 设计意图 |
|---|---|---|---|
| 每日打卡 | +1 | 1次/天 | 培养打开习惯，零成本高粘性 |
| 看广告 | +5 | 3次/天 | 变现核心路径，主动触发 |
| 邀请激活 | +50 | 无上限 | 裂变主引擎 |
| 完成训练 | +2 | 1次/天 | 捆绑核心行为，"越练越赚" |
| 写训练笔记 | +1 | 1次/天 | 内容生产激励 |

**等价互换原则**：看1次广告=+5积分，解锁1份详细报告=5积分。用户看完广告立刻就能解锁，或攒几天积分再解锁——路径等价，自由选择。

### 2.2 消耗分层

| 层级 | 积分 | 内容 | 回本周期 |
|---|---|---|---|
| 轻量 | 5 | 1份详细训练报告 | 看1广告 / 攒5天打卡 |
| 中量 | 30-80 | 分析工具 / 挑战任务 | 看6-16广告 |
| 重量 | 150-250 | 精品教学 / 稀缺体验 | 看30-50广告 |

## 三、双轨解锁机制

### 3.1 正常模式（广告开关开启）

每个被锁定功能弹出一个选择面板：

```
┌─────────────────────────────────┐
│  🔒 详细训练报告                  │
│                                 │
│  ┌───────────┐  ┌───────────┐   │
│  │ 📺 看广告  │  │ 🪙 花积分  │   │
│  │  免费解锁  │  │  5积分     │   │
│  └───────────┘  └───────────┘   │
│                                 │
└─────────────────────────────────┘
```

无论选哪条路径，解锁后体验完全相同。

### 3.2 广告关闭模式（广告开关关闭）

广告总开关关闭后：
- 所有"看广告"按钮消失
- 双轨选择面板变为纯积分消耗面板
- 提示文案："该功能需要消耗 XX 积分解锁"

```
┌─────────────────────────────────┐
│  🔒 详细训练报告                  │
│                                 │
│       🪙 消耗 5 积分解锁          │
│                                 │
└─────────────────────────────────┘
```

### 3.3 广告总开关设计

- 位置：设置页新增"广告设置"开关
- 作用域：全局生效，关闭后所有广告入口隐藏
- 实现：`AdService.shouldShowRewarded()` 和 `getNativeBannerWidget()` 受开关控制
- 入口：`Storage.getSettings()['adsEnabled']`（默认 true）

- 其余逻辑（HMAC验证/防自邀/一码一绑）完全不变

## 六、广告集成设计

### 6.1 模拟广告（v1阶段）

新增 `SimulatedAdService` 继承 `AdService`：

```
用户点击"看广告" → 弹出全屏模拟广告页（3秒倒计时+跳过按钮）
→ 倒计时结束 → 回调 AdResult.success → 获得5积分 → 解锁对应功能
```

### 6.2 预留接口

`AdService` 抽象类不变，未来替换为真实SDK时新增 `RealAdService implements AdService`，积分逻辑零改动。

### 6.3 防刷限制

每日看广告上限3次，在 `PointsService` 内校验。

### 6.4 广告总开关

- `Storage.getSettings()['adsEnabled']`（默认 true）
- 开关关闭 → `AdService.shouldShowRewarded()` 返回 false
- 开关关闭 → 所有 UI 层广告按钮隐藏

## 七、存储设计

### 7.1 settings 表新增字段

```dart
'points': 0,                          // 当前积分余额
'pointsEarnedTotal': 0,               // 累计赚取（成就/分析用）
'pointsSpentTotal': 0,                // 累计消耗
'lastCheckInDate': '2026-07-16',      // 上次打卡日期
'adsWatchedToday': 0,                 // 今日已看广告次数
'adsWatchedDate': '2026-07-16',       // 广告次数重置日期
'adsEnabled': true,                   // 广告总开关
'unlockedFeatures': '["heatmap"]',    // 已解锁功能ID列表（JSON）
```

### 7.2 积分交易日志

```dart
// settings 表 'pointsLog' 字段，JSON数组，最多保留50条
// [{'time': 1721123456, 'delta': +5, 'source': 'ad', 'balance': 15}, ...]
```

### 7.3 PointsService 核心接口

```dart
class PointsService {
  static final PointsService instance = PointsService._();

  int get points => Storage.getSettings()['points'] ?? 0;
  Future<void> addPoints(int amount, String source) async;
  Future<bool> spendPoints(int amount, String reason) async;
  bool isFeatureUnlocked(String featureId);
  Future<bool> unlockFeature(String featureId, int cost) async;
  Future<bool> dailyCheckIn() async;       // 已打卡返回false
  Future<AdResult> watchAd() async;        // 上限3次/天
  List<Map<String, dynamic>> getPointsLog();
}
```
