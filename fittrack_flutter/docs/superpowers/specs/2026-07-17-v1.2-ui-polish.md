## 设计决策总览

### #1 首页 Banner — 卡片式大图轮播

**问题**：当前 110 高度 `左图标方块 + 标题副标题 + 右箭头` 列表样式，视觉单薄。

**目标**：大视觉冲击、有设计感、banner 类型色彩分明。

**新规格**：
- 整卡高度 150 (替代 110)
- 背景：基于 type 的深色线性渐变（teaching=accentGlow `#FF6B35` 深橙 → 暗色 / premium=warningColor `#F59E0B` 金 → 暗色 / invitation=successColor `#22C55E` 绿 → 暗色 / achievement=purple `#A855F7` 紫 → 暗色）
- 内容布局：左上方 16px bold 白色大标题 + 下方 13px 半透明白副标题，左下方小 CTA 标签（如"立即查看 →" 12px accent 色圆角胶囊），右侧装饰几何（Positioned 圆形光晕 + 小 emoji/badge 浮动）
- 底部指示器：居中胶囊（当前页宽 16px 圆角 3px 实色，其他 6px 边框式）
- 圆角 16 + 同类型 0.08 边框
- 沿用 PageView.builder + 5 秒自动轮播 + onTap 路由跳转

**代码改动范围**：
- 修改 `lib/widgets/recommendation_banner.dart`（高度、布局、装饰、指示器）
- 不修改 `lib/services/recommendation_service.dart`（BannerItem 数据模型不变）
- 类型色调映射扩展：在 `_bgColor()` 返回深色 + 浅色两值用于渐变

- 荣誉墙数据：`AchievementService.instance.getAll()` 中 `unlocked==true` 的项
- 成就墙数据：`AchievementService.instance.getAll()` 全部项

**新建 `lib/pages/honor_wall_page.dart`**：
- PageHeader + 返回

- 成就墙改为列表式：按 category 分组，每项显示图标 + 标题 + 描述 + 进度条（未解锁）/ 对勾（已解锁）

## 统计页图表增强（新增）

### 新增图表总览

| 图表 | 类型 | 数据来源 | 位置 |
|------|------|----------|------|
| 训练容量趋势 | 柱状图 | _records 按周聚合 totalWeight | 训练频率下方 |
| 动作热度榜 | 水平条形图 | _records 按 exercise 计数 | 肌群分布下方 |
| 训练时长趋势 | 折线图 | _records 按周聚合 avg duration | 训练容量下方 |
| PR 进度追踪 | 多折线 | _records 按 exercise 追踪 max weight | 时长趋势下方 |

### 图表详细规格

#### 训练容量趋势（Weekly Volume）
- 类型：柱状图（周维度）
- 数据：`_records` 按周分组，计算每周 totalWeight（所有 sets 的 weight * reps 之和）
- 展示：最近 6 周，每根柱子高度 = 当周容量 / 最大周容量 * 120
- 柱顶显示数值（kg），柱底显示周标签（W1/W2/...）
- 空数据时显示"暂无训练数据"占位

#### 动作热度榜（Exercise Popularity）
- 类型：水平条形图
- 数据：`_records` 中所有 setRecords 按 exercise 计数（出现次数）
- 展示：Top 5 动作，每行 = 动作名 + 水平条形（宽度 = count / maxCount * 可用宽度）+ 次数
- 左侧小圆图标（12px accentGlow）+ 动作名（13px）+ 条形（accentGlow 渐变）+ 次数（12px textMuted）
- 空数据时隐藏

#### 训练时长趋势（Duration Trend）
- 类型：折线图（周维度）
- 数据：`_records` 按周分组，计算每周平均训练时长（分钟）
- 展示：最近 6 周，折线连接各周数据点，数据点圆圈 6px accentGlow
- 折线下方填充半透明 accentGlow（0.1）
- Y 轴范围自适应（0 ~ max * 1.2）
- 空数据时隐藏

#### PR 进度追踪（PR Progression）
- 类型：多折线（每个 top exercise 一条线）
- 数据：取动作热度 Top 3 的 exercise，追踪每周 max weight
- 展示：3 条不同颜色折线（accentGlow / successColor / warningColor）+ 图例
- 数据点显示具体数值（kg）
- 空数据时隐藏
