| 决策点 | 选择 | 理由 |

| 实现范围 | 10 条全部本次实现 | 一次性交付完整优化，避免多轮迭代 |

```dart
class RecommendationService {
  /// 根据用户画像生成 banner 列表
  static List<BannerItem> generateBanners() {
    final settings = Storage.getSettings();
    final body = Storage.getBodyData();
    final goal = settings['fitnessGoal'] ?? 'gain'; // gain/lose/maintain
    final level = settings['fitnessLevel'] ?? 'beginner';
    final gender = settings['gender'] ?? 'male';
    final bmi = _calcBMI(body);

    final items = <BannerItem>[];

    // 1. 教学推荐（60%）：按目标筛选匹配的教学/课程
    items.addAll(_getTeachingBanners(goal, level));

    // 2. 付费方案推广（25%）：精选付费课程
    items.addAll(_getPremiumCourseBanners(goal));

    // 3. 内部推广（15%）：邀请有礼、成就挑战
    items.add(BannerItem.invitation());
    if (_shouldShowAchievementChallenge(settings)) {
      items.add(BannerItem.achievementChallenge());
    }

    return items..shuffle(Random(seed: DateTime.now().day)); // 每日固定顺序
  }
}

class BannerItem {
  final String type; // teaching / premium / invitation / achievement
  final String title;
  final String subtitle;
  final String? imageUrl;    // 程序化插画或 asset 路径
  final String? route;       // 点击跳转路由
  final Map<String, dynamic>? extra; // 附加参数（如 featureId）
}
```

**Banner 组件**: 新建 `lib/widgets/recommendation_banner.dart`：

**问题**: [home_page.dart:895](file:///d:/app/projects/health_training/fittrack_flutter/lib/pages/home_page.dart#L895) `_buildCurrentPlanCard` 仅展示"第 X/Y 周"（周进度），未展示计划重复次数与当前轮次进度。

**方案**:
1. 在 `_buildCurrentPlanCard` 中计算轮次信息：
   ```dart
   final createTime = plan['createTime'] as int? ?? DateTime.now().millisecondsSinceEpoch;
   final totalWeeks = plan['totalWeeks'] as int? ?? 8;
   final startDate = DateTime.fromMillisecondsSinceEpoch(createTime);
   final elapsedDays = DateTime.now().difference(startDate).inDays;
   final elapsedWeeks = elapsedDays ~/ 7;
   final totalRounds = (plan['totalRounds'] as int?) ?? 1; // 默认 1 轮
   final currentRound = (elapsedWeeks ~/ totalWeeks) + 1;
   final weekInRound = (elapsedWeeks % totalWeeks) + 1;
   final roundProgress = (weekInRound / totalWeeks * 100).clamp(0, 100);
   final overallProgress = (currentRound / totalRounds * 100).clamp(0, 100);
   ```
2. 卡片新增双行进度展示：
   - 第 1 行：`第 $currentRound/$totalRounds 轮 · 第 $weekInRound/$totalWeeks 周`（标题旁）
   - 第 2 行进度条：当前轮次内进度（roundProgress）
   - 第 3 行小字：`整体进度 $overallProgress%` + 细进度条
3. 若 `totalRounds == 1`，仅展示原有周进度，不展示轮次行（避免冗余）。
