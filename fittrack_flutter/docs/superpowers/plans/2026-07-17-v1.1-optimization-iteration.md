# v1.1 优化迭代实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实施 v1.1 优化迭代 10 项需求，覆盖 bug 修复、积分体系、首页改版、教学重构、社交分享、成就荣誉墙 6 个 Phase。

**Architecture:** 基于现有 v1 代码库增量改造。积分/成就数据沿用 `PointsService` + `AchievementService` + `Storage.getSettings()` 模式。教学内容重构为 `ContentBlock` 富文本块结构。推荐系统为纯函数 `RecommendationService.generateBanners()`。

**Tech Stack:** Flutter (Dart >=2.19.6 <3.0.0), go_router ^6.5.0, share_plus ^7.0.0, path_provider ^2.1.0

## Global Constraints

- 项目 SDK 约束：Dart >=2.19.6 <3.0.0
- go_router ^6.5.0 API：使用 `state.params`（非 `state.pathParameters`），`context.push`/`context.go`
- 平台判断统一使用 `utils/platform_utils.dart` 中的 `isOhos` getter
- FitTrackColors 主题扩展：bgCard/bgSecondary/bgElevated/borderColor/accentGlow/textPrimary/textSecondary/textMuted/successColor/warningColor
- commit 风格：`feat:`/`fix:`/`refactor:`/`chore:`/`docs:` 前缀，英文简短描述
- PageHeader 组件：`isTabPage: true` 用于 tab 页（无返回），`isTabPage: false` + `onBack: () => context.pop()` 用于全屏页
- AppShell IndexedStack 缓存模式：tab 页通过 `_children` 数组渲染，`widget.child` 未使用

class RecommendationService {
  static List<BannerItem> generateBanners() {
    final settings = Storage.getSettings();
    final goal = settings['fitnessGoal'] as String? ?? 'gain';
    final level = settings['fitnessLevel'] as String? ?? 'beginner';

    final items = <BannerItem>[];

    // 1. 教学推荐（按目标筛选）
    final tutorials = TutorialLibrary.getBasic().where((t) {
      if (t.goal == null) return false;
      return t.goal!.name == goal || t.goal == FitnessGoal.all;
    }).take(3).toList();
    for (final t in tutorials) {
      items.add(BannerItem(
        type: 'teaching',
        title: t.name,
        subtitle: '推荐教学 · ${t.difficulty}',
        icon: 'school',
        route: '/tutorial/${t.id}',
      ));
    }

    // 2. 付费方案推广
    final premiumCourses = CourseLibrary.courses.where((c) => c.pointsCost > 0).take(2).toList();
    for (final c in premiumCourses) {
      items.add(BannerItem(
        type: 'premium',
        title: c.title,
        subtitle: '${c.pointsCost} 积分解锁',
        icon: 'lock',
        route: '/course/${c.id}',
      ));
    }

    // 3. 内部推广
    items.add(BannerItem.invitation());
    items.add(BannerItem.achievementChallenge());

    // 每日固定顺序（基于日期 seed）
    items.shuffle(Random(seed: DateTime.now().day));
    return items;
  }
}
