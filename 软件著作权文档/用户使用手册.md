# FitTrack燃力健身训练追踪系统 用户使用手册

## 一、软件概述

### 1.1 软件名称

FitTrack燃力健身训练追踪系统（以下简称"本软件"）

### 1.2 软件简介

FitTrack燃力是一款面向健身爱好者的多平台训练追踪应用，采用纯本地单机架构，所有数据存储在设备本地，无需网络连接。本软件帮助用户科学管理训练计划、记录训练数据、追踪健身进度，为健身爱好者提供专业的数字化训练管理工具。

### 1.3 适用平台

- HarmonyOS（含桌面卡片、实况窗等特色功能）
- Android
- iOS
- macOS
- Windows
- Linux
- Web

---

## 二、安装与启动

### 2.1 安装方式

**Android平台**：
1. 下载APK安装包
2. 允许安装未知来源应用
3. 点击安装包完成安装

**HarmonyOS平台**：
1. 下载HAP安装包
2. 通过文件管理器打开安装包
3. 按照提示完成安装

**iOS平台**：
1. 通过App Store下载安装
2. 或通过TestFlight安装测试版本

**其他平台**：
- macOS/Windows/Linux：下载对应平台的安装包
- Web：通过浏览器访问Web版本

### 2.2 首次启动

首次启动本软件时，将按以下流程进行初始化：

1. **隐私政策确认**：阅读并同意隐私政策
2. **新手引导**：了解软件核心功能
3. **健身问卷**：填写个人健身信息（性别、目标、水平）
4. **计划推荐**：根据问卷结果获取个性化训练计划推荐
5. **自动生成档案**：系统自动生成用户名和头像

## 三、功能使用指南

### 3.1 首页

首页是软件的核心入口，展示今日训练概览和快捷功能。

**主要功能**：
- 今日训练状态展示
- 快捷入口（开始训练、查看计划、查看统计）
- 连续训练天数（streak）展示
- 最近训练记录

**操作方式**：
- 点击"开始训练"进入训练执行页面
- 点击各快捷入口跳转对应功能页面

### 3.2 训练计划

#### 3.2.1 查看计划

在计划页面可以查看所有训练计划：
- 计划名称、类型、难度
- 当前进度和状态
- 训练频率和总周数

#### 3.2.2 创建计划

1. 点击"新建计划"按钮
2. 填写计划基本信息：
   - 计划名称
   - 计划类型（三分化/全身训练等）
   - 难度等级（入门/进阶/高级）
   - 训练频率（3天/周、6天/周等）
   - 总周数
3. 设置每日训练内容
4. 保存计划

#### 3.2.3 编辑/删除计划

- 点击计划卡片进入详情页
- 在详情页可编辑计划信息或删除计划

### 3.3 训练执行

训练执行是软件的核心功能，用于执行训练计划并记录数据。

#### 3.3.1 开始训练

1. 在首页或计划页面选择要执行的计划
2. 选择训练日
3. 点击"开始训练"

#### 3.3.2 训练过程

训练执行页面显示：
- 当前动作名称
- 当前组数/总组数
- 重量和次数输入框
- 休息倒计时

**操作流程**：
1. 完成一组训练后，输入重量和次数
2. 点击"完成一组"
3. 系统自动开始休息倒计时
4. 倒计时结束后，自动进入下一组或下一个动作
5. 重复以上步骤直至完成所有动作

#### 3.3.3 休息提醒

训练过程中，组间休息结束时将通过以下方式提醒：
- 设备振动
- 通知提醒（Android/iOS）
- 桌面卡片更新（HarmonyOS）
- 实况窗显示（HarmonyOS）

#### 3.3.4 完成训练

所有动作完成后：
1. 系统自动保存训练记录
2. 更新统计数据
3. 显示训练总结

### 3.4 统计分析

统计页面展示用户的训练数据和进度趋势。

**主要功能**：
- 总训练次数、总时长、总重量、总组数
- 周度训练统计图表
- 肌肉分布分析
- 个人记录追踪

### 3.5 训练记录

记录页面展示所有历史训练记录。

**主要功能**：
- 按时间排序的训练记录列表
- 每条记录的详细信息（日期、时长、动作、组数）
- 记录详情查看

### 3.6 身体数据

身体数据页面用于记录和追踪身体指标。

**可记录数据**：
- 身高
- 体重
- 体脂率
- 胸围、腰围、臀围
- 臂围、大腿围
- 目标体重
- 静息心率

**主要功能**：
- BMI实时计算
- 体重趋势折线图
- 身体变化趋势分析
- 历史数据查看

### 3.7 健身卡管理

健身卡管理页面用于管理健身房会员卡信息。

**主要功能**：
- 添加健身卡（名称、健身房、类型、价格、日期）
- 查看剩余次数/到期日
- 编辑/删除健身卡信息

### 3.8 个人中心

个人中心页面展示用户个人信息和设置入口。

**主要功能**：
- 用户名和头像展示
- 健身目标展示
- 设置入口
- 数据管理入口

### 3.9 设置

设置页面提供软件的各项配置功能。

**主要设置项**：
- 重量单位（kg/lb）
- 默认休息时间
- 默认组数/次数/重量
- 训练提醒时间
- 主题设置
- 数据管理（导出/导入/清空）

### 3.10 主题设置

本软件提供7套视觉主题：

| 主题名称 | 风格描述 |
|----------|----------|
| 活力运动 | 动感活力，年轻有劲（默认） |
| 硬核铁馆 | 男性健身玩家风格 |
| 柔美花语 | 女性优雅健身风格 |
| 长者关怀 | 大字清晰易读 |
| 清新极简 | 简洁留白美学 |
| 赛博霓虹 | Z世代潮流风格 |
| 黑金尊享 | 商务精英品质风格 |

**切换方式**：
1. 进入设置页面
2. 点击"主题设置"
3. 滑动预览各主题效果
4. 选择喜欢的主题并应用

## 四、HarmonyOS特色功能

### 4.1 桌面卡片

本软件支持HarmonyOS桌面卡片功能，可在桌面实时查看训练状态。

**卡片状态**：
- **空闲态**：显示今日训练概览、连续天数、训练提醒时间
- **训练态**：显示当前动作、组数进度
- **休息态**：显示休息倒计时

**添加方式**：
1. 长按桌面空白处
2. 选择"卡片"或"服务卡片"
3. 找到FitTrack燃力
4. 选择卡片样式并添加到桌面

### 4.2 实况窗

训练休息期间，HarmonyOS设备将显示实况窗胶囊，实时展示休息倒计时。

**功能说明**：
- 休息开始时自动显示
- 点击胶囊可返回应用
- 休息结束后自动消失

### 4.3 后台代理提醒

本软件支持HarmonyOS后台代理提醒功能，确保休息提醒在后台可靠触发。

## 五、数据管理

### 5.1 数据导出

1. 进入设置页面
2. 点击"数据管理"
3. 选择"导出数据"
4. 选择保存位置
5. 导出完成

导出数据为JSON格式，包含：
- 所有训练计划
- 所有训练记录
- 设置信息
- 统计数据

### 5.2 数据导入

1. 进入设置页面
2. 点击"数据管理"
3. 选择"导入数据"
4. 选择要导入的文件
5. 确认导入

**注意**：数据导入将覆盖现有数据，请谨慎操作。

### 5.3 数据清空

1. 进入设置页面
2. 点击"数据管理"
3. 选择"清空数据"
4. 确认操作

**警告**：此操作将删除所有数据且不可恢复，请提前备份。

## 六、常见问题

### 6.1 如何开始第一次训练？

1. 首次启动完成新手引导
2. 填写健身问卷
3. 获取推荐计划
4. 在首页点击"开始训练"

### 6.2 如何修改训练计划？

1. 进入"计划"页面
2. 点击要修改的计划
3. 在详情页点击"编辑"
4. 修改后保存

### 6.3 训练数据会丢失吗？

本软件采用纯本地存储，数据存储在设备SQLite数据库中。只要不卸载应用或清空数据，数据不会丢失。建议定期导出备份。

### 6.4 如何更换主题？

1. 进入"设置"页面
2. 点击"主题设置"
3. 选择喜欢的主题
4. 点击"应用此主题"

### 6.5 如何设置训练提醒？

1. 进入"设置"页面
2. 点击"提醒设置"
3. 设置提醒时间
4. 开启提醒开关

### 6.6 桌面卡片不显示怎么办？

1. 检查是否已添加桌面卡片
2. 检查应用是否有桌面卡片权限
3. 尝试重新添加卡片
4. 重启应用

## 七、注意事项

1. **数据备份**：建议定期导出数据备份，防止数据丢失
2. **权限授权**：首次使用请授权通知权限，以确保提醒功能正常工作
3. **存储空间**：确保设备有足够存储空间（建议100MB以上）
4. **系统版本**：确保设备系统版本满足最低要求
5. **隐私保护**：本软件为纯本地应用，不会上传任何用户数据
