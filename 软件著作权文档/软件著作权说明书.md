## 二、软件概述

### 2.1 软件用途

FitTrack燃力是一款面向健身爱好者的多平台训练追踪应用，采用纯本地单机架构（数据全部存储在设备本地，不上传服务器）。本软件旨在帮助用户科学管理训练计划、记录训练数据、追踪健身进度，为健身爱好者提供专业的数字化训练管理工具。

### 2.2 软件特点

1. **跨平台支持**：基于Flutter框架实现一次开发多端部署，覆盖HarmonyOS、Android、iOS、macOS、Windows、Linux及Web七大平台
2. **纯本地存储**：所有数据存储于设备本地SQLite数据库和SharedPreferences，无需网络连接，保护用户隐私
3. **HarmonyOS深度适配**：支持HarmonyOS桌面卡片（Form Kit）、实况窗（LiveViewKit）、后台代理提醒等系统级特性
4. **多主题系统**：内置7套精心设计的视觉主题，满足不同用户审美偏好
5. **智能提醒机制**：三重休息提醒机制（Dart Timer + Android定时通知 + OHOS代理提醒），确保训练节奏

### 2.3 目标用户

- 健身爱好者
- 健身房会员
- 私人教练及学员
- 需要训练数据管理的运动人群

## 三、技术架构

### 3.1 整体架构

本软件采用经典分层架构设计，以Flutter跨平台框架为核心，结合原生平台能力扩展：

```
┌─────────────────────────────────────────────────────┐
│                    表现层 (UI Layer)                  │
│   HomePage / TrainingPage / StatsPage / PlanPage /   │
│   ProfilePage / SettingsPage / ExercisePage / ...    │
├─────────────────────────────────────────────────────┤
│                   路由层 (Routing)                    │
│        go_router (声明式路由 + ShellRoute)            │
├─────────────────────────────────────────────────────┤
│                  组件层 (Widgets)                     │
│   BottomNav / StatCard / PageHeader / CommonWidgets  │
├─────────────────────────────────────────────────────┤
│                  服务层 (Services)                    │
│   RestNotification / FormKit / OhosReminder /        │
│   Permission / UserProfileGenerator                  │
├─────────────────────────────────────────────────────┤
│                   数据层 (Data)                       │
│   Storage(混合持久化) + DatabaseHelper(SQLite)        │
│   + SharedPreferences(轻量KV)                        │
├─────────────────────────────────────────────────────┤
│              原生桥接层 (Native Bridge)               │
│   MethodChannel → EntryAbility (HarmonyOS)           │
│   FormExtensionAbility / LiveViewKit                 │
└─────────────────────────────────────────────────────┘
```

### 3.2 技术选型

| 技术/框架 | 版本 | 用途 |
|-----------|------|------|
| Flutter SDK | >=2.19.6 <3.0.0 | 跨平台UI框架 |
| Dart | 2.19.6+ | 编程语言 |
| sqflite | OHOS定制版 | SQLite数据库操作 |
| shared_preferences | OHOS定制版 | 轻量键值存储 |
| go_router | ^6.5.0 | 声明式路由管理 |
| flutter_local_notifications | OHOS定制版 | 本地通知 |
| timezone | ^0.9.4 | 时区支持 |
| permission_handler | OHOS定制版 | 权限管理 |
| ArkTS/ETS | - | HarmonyOS原生开发 |

### 3.3 数据持久化策略

本软件采用混合持久化方案：

- **SQLite数据库**：存储结构化数据（训练计划、训练记录、健身卡信息）
- **SharedPreferences**：存储轻量键值对（设置、统计数据、身体数据）
- **内存缓存**：启动时预加载数据到内存，同步接口直接操作缓存并异步落盘

### 3.4 状态管理

本软件未引入独立状态管理框架（如Provider/Bloc/Riverpod），采用以下组合方案：

- **Storage内存缓存**：维护所有数据的缓存列表
- **ValueNotifier**：跨页面数据变更通知
- **setState**：页面内部状态管理
- **GoRouter**：路由状态管理

## 九、软件创新点

1. **纯本地架构设计**：所有数据存储于设备本地，无需服务器支持，保护用户隐私
2. **HarmonyOS深度集成**：充分利用HarmonyOS桌面卡片、实况窗、后台代理提醒等系统级能力
3. **三重休息提醒机制**：Dart Timer + Android定时通知 + OHOS代理提醒，确保训练节奏不中断
4. **智能用户档案生成**：基于问卷自动生成个性化用户名和头像
5. **多主题视觉系统**：7套精心设计的主题，支持实时切换和卡片主题同步
6. **混合持久化策略**：SQLite + SharedPreferences + 内存缓存，兼顾性能与数据可靠性
