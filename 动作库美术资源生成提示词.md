# 动作库美术资源生成提示词

> 适用平台：Midjourney / DALL·E 3 / Stable Diffusion SDXL
> 使用方式：将每段 prompt 复制到 AI 图像生成工具中即可

---

## 通用风格设定（所有提示词共享）

所有提示词统一使用以下**风格前缀**：
```
fitness training illustration, clean flat vector style, professional exercise guide, gym setting, neutral background, anatomical accuracy, correct form demonstration, high contrast, clear silhouette, fitness instructional diagram, white background or soft gradient background, 2D illustration style, no text, no watermark, no logo
```

以下所有 prompt 中请在前面加上上述前缀，形成完整 prompt。

> 提示：如果使用 Midjourney，请在末尾加上 `--ar 1:1`（预览图）或 `--ar 4:3`（步骤图）`--v 6`；
> 如果使用 SDXL，image_size 参数预览图用 `square`，步骤图用 `landscape_4_3`。

## 八、使用说明

### 生成图片的建议命名规范

建议将生成的图片按以下规则命名，便于对接代码：

**预览图**：`{action_id}_{英文动作名}_preview.png`
- 示例：`e1_barbell_bench_press_preview.png`

**步骤图**：`{action_id}_{英文动作名}_step{N}.png`
- 示例：`e1_barbell_bench_press_step1.png`、`e1_barbell_bench_press_step2.png`

### 在项目中的存放位置

```
fittrack_flutter/assets/images/exercises/
├── e1_barbell_bench_press_preview.png
├── e1_barbell_bench_press_step1.png
├── e1_barbell_bench_press_step2.png
├── e1_barbell_bench_press_step3.png
├── e2_dumbbell_fly_preview.png
...
```

### 生成参数建议

| 参数 | 预览图 | 步骤图 |
|:---|:---:|:---:|
| 画幅比例 | 1:1 (square) | 4:3 (landscape) |
| 分辨率 | 1024×1024 | 1024×768 |
| 风格 | 清晰扁平矢量 | 清晰扁平矢量 |
| 背景 | 浅色纯色/渐变 | 浅色纯色/渐变 |
